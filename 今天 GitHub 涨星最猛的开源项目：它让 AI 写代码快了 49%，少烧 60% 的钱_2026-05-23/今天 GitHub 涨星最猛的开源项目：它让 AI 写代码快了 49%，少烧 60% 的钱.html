今天 GitHub 上，有一个项目单日新增了 3688 颗星

我每天都会扫一眼 GitHub Trending，不为别的，就是想知道全球的开发者今天在用手投票给什么。

今天涨得最猛的，不是什么新出的大模型，也不是哪家大厂的新框架——是一个叫 codegraph 的工具，一天新增了 3688 颗 star，累计已经超过 16000。

它解决的问题，如果你在用 Claude Code、Cursor 或者 Codex 写代码，你大概率每天都在遇到——只是你可能没意识到这是个问题。

AI 写代码的时候，在偷偷做一件很蠢的事

当你让 Claude Code 或者 Cursor 帮你修改一段逻辑的时候，它背后其实在做什么？

它会派出一堆"探索代理"，用 grep 搜文件，用 glob 扫目录，一遍一遍地读代码，试图搞清楚你的项目结构。每次调用这些工具，都要消耗 token。项目越大，搜的次数越多，token 用得越多，速度越慢，费用越高。

用一个不那么准确但很直觉的类比：相当于一个新员工每次想找一份文件，都要把整个办公室翻一遍，而不是去查一下文件索引。

codegraph 做的事，其实非常简单

它给你的代码仓库建一个预索引的知识图谱。

不是等 AI 每次动手才去搜文件——而是提前把代码里的符号关系、函数调用链、模块依赖全部整理好，存成一张图。AI 需要什么信息的时候，直接查图，不需要再重新扫文件。

就这一个改变，效果是这样的：

  • 减少 59% 的 token 消耗（中位数，跨 7 个真实代码库测试）
  • 提速 49%
  • 减少 70% 的工具调用次数

对大型项目效果更明显。拿 VS Code 的源码仓库（TypeScript，约一万个文件）测试，工具调用减少了 72%，token 使用减少了 73%。

支持的语言和框架很全

对于用各种语言做项目的人来说，这件事比较重要：codegraph 支持 19 种以上的编程语言，包括 TypeScript、Python、Go、Rust、Java、C#、PHP、Ruby……

框架层面也覆盖了 Django、Flask、FastAPI、Express、NestJS、Laravel 这些常用的。

基本上，不管你是做 Web 后端、Python 脚本、还是 Go 微服务，都能直接用。

除了 codegraph，今天 Trending 还有几个值得看一眼的

今天的 GitHub Trending 里，还有两个项目我觉得可以顺手介绍一下。

Understand-Anything（18,000+ stars，今日 +1,391）

把任何代码库变成一个可以交互式探索的知识图谱——不只是搜索代码，而是可以向它提问："这个模块和那个模块之间的关系是什么？""这个函数被哪些地方调用了？"

对于刚接手一个陌生大型项目、需要快速摸清脉络的人，这个工具的体验可能比直接让 AI 解释代码要顺很多。

RuView（63,000+ stars，今日 +992）

这个项目有点不一样——用 WiFi 信号做室内人员感知，不需要任何摄像头。

检测到有人、几个人、呼吸率、心率、姿态……用的是 WiFi 路由器的信道状态信息。硬件成本：一个 ESP32 大概 $9。

它的应用场景横跨老年护理、零售客流分析、工业安全……已经 63,000 颗 star 了，说明这个方向有相当多的人在认真研究。
