两小时的全案

大家好啊，我是累瘫了的甲木。

参加完 WAIC，感觉身体被掏空。但是看到好玩的东西必须要给大家分享，强行开机！

前段时间我们不是搞了一本 WorkBuddy 蓝皮书么，所以对这个团队的动作也非常关注，

这次，他们又带着诚意满满的新作来了，

我把一只企鹅从参考图一路做成了一套 IP 全案

这是我用腾讯最近刚上线的妙境 Miora花了 2 个小时做出来的

它把自己定位为AI 创意智能体工作室：用户提出目标，它负责理解需求、拆解任务，再调度不同的专业 Buddy，在同一块画布上完成整个项目。

接下来给大家看下整个过程是怎么操作，大家也可以很轻松的做出自己的 IP 全案设计

01

PART


它没有一上来就生图

NO RUSH TO DRAW · STEP 01

我一开始在 Miora 里选了IP 设计全案。

我输入的是一句很笼统的话：

PROMPT 我想设计一套完整的 IP 设计全案

如果是普通生图工具，大概率会直接给我几张“看起来像 IP 的图”。

但 Miora 没有直接开始画。它先问我：这个角色是什么物种？是什么性格？主色调是什么？有没有名字、爱好、口头禅、星座、MBTI？

这一步让我有点意外。

它不是先追求“出图”，而是先把角色当成一个可以长期延展的对象来处理。

我上传了一张企鹅参考图

它识别出了几个核心特征：黑白身体、橙色嘴和脚、红围巾、圆滚滚的比例、大眼睛，以及 3D 软萌玩具质感。

接着，它先生成了两类基础物料：角色工牌档案卡和标准三视图。

这其实很关键。因为后面不管做表情包、盲盒还是周边，都要靠这套基础规范保持一致。

02

PART


真正有用的是，它会把任务拆开

TASK SPLIT · STEP 02

确认角色之后，Miora 开始把整个 IP 全案拆成不同品类：

表情包贴纸、角色换装卡、材质盲盒海报、电影场景海报、周边 Mockup、材质延展目录。

其中最直观的一项，是把企鹅延展成了一组3D 毛绒风格的表情贴纸。大笑、生气、打招呼、疑惑、眨眼、唱歌、加油、星星眼和大哭，基本覆盖了日常聊天里常用的情绪

它不仅是把同一个角色复制九遍，而是通过眼神、嘴型、动作和小图形，让一个基础形象继续变成可以传播、可以使用的内容

再往外延展，Miora 还把企鹅放进了赛车追逐、电影院、太空探索和海盗船四种完全不同的故事环境。角色开始拥有自己的行动和情节

这类 IP 场景延展图可以继续作为海报、广告或短片分镜的视觉起点，也让我更直观地看到：一个角色建立基础规范后，还能沿着多少方向继续生长

这一步就开始和“单次生图”拉开差别了。

不需要我分别去开六个工具、写六套 prompt，而是它在同一个项目里，把任务拆给不同方向的专家处理。最后这些图都回到同一块画布上。

这也是我觉得 Miora 这类智能体产品最有价值的地方。

当你只要一张图时，生图工具就够了。但当你要的是一套完整交付，它需要的不只是“画得好”，而是能理解：哪些东西要先做，哪些东西是基础规范，哪些东西可以并行延展，哪些东西必须保持一致。

03

PART


第一次结果并不完美，但这反而是重点

ITERATE · STEP 03

第一版结果出来后，我并不是都满意。

比如盲盒系列。

第一版的 6 只企鹅虽然有不同材质和道具，但都像“排排站”的复制粘贴。底座也都是白色圆柱，看起来很普通。

我就说了一句：

PROMPT 感觉很普通，不如泡泡玛特的盲盒有设计感

这句话其实很口语，也不算一个精确 prompt。

但 Miora 把问题拆得很细：姿态复用、底座普通、缺少故事感、像流水线、没有潮玩该有的生命力。

然后它把盲盒从“材质实验”改成了“企鹅陪伴纪念系列”：回家款、陪伴款、打工款、旅行款、生日款、纪念款。每一款都有自己的动作和微缩底座。

这段是整个过程中我最有感的一段。

真正让我觉得它不是黑盒的，不是第一次生成有多完美，而是我指出问题后——

它能理解我说的“普通”到底普通在哪

04

PART


我可以在画布里直接改，而不是整张重来

CANVAS EDIT · STEP 04

另一个很实用的点，是画布编辑。

我在电商详情页里发现标题还用旧称，于是直接圈出标题区域，输入：

PROMPT 文字改为企鹅

它没有把整张图推倒重来，而是在保留原本排版、图像和结构的基础上，把标题改成了“企鹅 萌趣变装系列”。

画布里还能看到更多编辑能力：背景移除、文字替换、框选编辑、生成全景图、编辑元素、动作生成、扩图、裁剪、重打光、调整视角、反推提示词、矢量化。

这对创作来说很重要。

因为生成结果经常不是“一次到位”，而是80 分之后还要一点点修。

能不能在原图上继续改，决定了这个工具到底能不能进入真实工作流

05

PART


从 IP 图，继续走到商品化物料

MERCHANDISE · STEP 05

后面我继续让它往商业物料方向走。

比如包装彩盒。

它会考虑盒型、主色、侧面图鉴、开盒提示、Spot UV、金箔、纸张质感，还会把包装盒和手办放在同一个展示场景里。

比如周边产品。

它生成过背包、陶瓷马克杯、卡片、钥匙扣。中间也有翻车：有一版 U 型颈枕漏掉了企鹅最核心的红围巾，整个 IP 一致性就断了。

我指出之后，它先想把颈枕改成一圈红围巾，但我觉得太丑了，又让它换成单品。最后它改成了陶瓷马克杯。

这段很真实。

做周边不是“把角色贴上去”就完事。一个红绳手柄可能显得廉价，一个颈枕图案穿帮会破坏整套 IP 的一致性。

再往下，它还生成了电商详情页和 16：9 新品横幅。

详情页里有KV、IP 故事、6 款图鉴、产品参数、工艺说明、预售按钮。横幅则更像发售广告，用左文右图的结构展示主视觉。

到这里，这个项目已经不像是“我生成了一些企鹅图”，而更像一套小型 Campaign。

06

PART


甚至还能推进到 3D 打印

3D PRINT · STEP 06

我还问了一个比较实际的问题：

PROMPT 做 3D 打印的话，如何做？

Miora 给出的回答不是“生成一个 3D 风格图片”，直接开始讲三视图、分件、打印工艺、支撑位置、打磨、喷漆和消光。

比如它会提醒：不要整只企鹅一次性打印。应该拆成头部、身体、肚皮、嘴、脚、围巾等分件，这样后期上色不容易溢色。

它也会建议不要用普通 FDM 打印，而是用更适合手办打样的SLA/DLP 光敏树脂。支撑结构尽量放在背面、底部和卡扣内部，不要在脸和肚皮上留下支撑痕。

我又让它基于当前企鹅生成一套适合 3D 打印的建模参考图：正面、侧面、背面，简化毛绒和复杂小配件，让围巾贴合身体，双脚落地，重心稳定，适合做 8cm 桌面摆件。

这一步对我来说很有意思。

因为它把“好看的视觉图”往“可制造的参考图”推进了一步。虽然最终如果真的要打印，还是需要建模师和打样流程，但它已经能帮你把需求讲清楚。

07

PART


最后，我把流程沉淀成 Skill

SAVE AS SKILL · STEP 07

做完这套企鹅 IP 全案后，我让 Miora 把这套流程保存成 Skill。

我给它的逻辑是：以后我只要上传一个宠物、人物或角色图，它就能按这次的流程继续执行。

流程大概是：

1

上传参考图

2

分析角色识别点

3

建立人设和三视图

4

生成表情包和盲盒

5

做周边 Mockup

6

做包装和详情页

7

做 3D 打印参考

8

支持局部修改

9

输出完整交付清单

Miora 不只是回复了一段文字，它还自动弹出了“发布技能到市场”的窗口。技能名、简介、版本号都已经填好，只剩最后确认发布。

后来我又点进技能页看了一眼，这件事就更明确了。Miora 的 Skill 不是藏在某个设置里，而是有一个专门的技能市场：内置技能、从市场安装的技能、我自己创建的技能，会放在同一个页面里管理。

我沉淀的“宠物/人物 IP 全案生成器”已经出现在技能列表中，并进入安全合规检测。之后换一只宠物、一个人物或品牌角色，都能直接复用这套流程。

Skill 的价值，就是把跑通的方法保存下来

包括任务怎么拆、效果怎么判断，以及出现问题后怎么调整

CONCLUSION · 2 HOURS

两个小时做下来，Miora 帮我完成了角色设定、表情包、盲盒、周边、包装、电商物料和 3D 打印参考。过程中有几次翻车，但都能继续沟通和修改，整个项目没有断掉。

这些结果距离真正生产还有一段路，细节、一致性和可制造性仍然需要设计师、建模师和打样团队把关。不过在创意前期，它已经能把一个模糊想法快速整理成一套可讨论、可修改的方案。

如果你也有想开发的宠物或角色，可以直接从“做一套 IP 全案”开始。跑通以后，再把流程保存成 Skill。下次换一个角色，就不用从头摸索了
