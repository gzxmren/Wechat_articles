我给腾讯 WorkBuddy 装了个「外挂」，AI 从此通宵替我打工
上周三晚上 11 点，我给 WorkBuddy 派了个大活：让它跑一批资料整理，预计两个多小时。我心想这下可以踏实睡了，AI 嘛，又不用打卡。
第二天早上 7 点，我打开电脑一看，血压直接拉满——任务停在 40%，屏幕上挂着一个"是否允许访问文件"的权限弹窗，从半夜一直挂到天亮。AI 就在那干等着我点"允许"，我俩大眼瞪小眼瞪了一整晚。
那一刻我就想：我到底是雇了个员工，还是养了尊佛？

01

01｜WorkBuddy 好用，但这几个槽点我忍很久了
先给不熟悉的朋友补个背景。WorkBuddy 是腾讯云代码助手推出的 AI Agent 办公工具，简单说就是给你配了个 AI 打工仔：你把任务丢给它，它自己拆解步骤、自己干活、自己交结果，还支持多个 Agent 并行跑。日常写方案、整理资料、批量处理文件，提效是真的明显。
但用得越狠，槽点攒得也越快。我自己总结下来就三条。
第一，切账号要扫码。我手里有两个账号，一个写方案、一个拿来测试。WorkBuddy 原生不支持多账号一键切换，每次换号都要退出登录重新扫码，一天折腾几次，真的扫到手抽筋。
第二，积分要手动领。WorkBuddy 有每日签到领积分的机制，一个账号点一次还行，账号一多就成了每天雷打不动的打卡负担，忘领了还心疼。
第三，也是最要命的：挂机跑任务，权限弹窗会打断。AI 干活的时候动不动就要授权——访问文件、执行命令，弹个窗安安静静等你确认。人不在，它就一直等，任务时长直接翻倍。半夜派的活，基本等于白派。

02

02｜WorkDaddy：700 多颗星的开源「外挂」
直到我在 GitHub 上刷到 WorkDaddy 这个开源项目，上面这些糟心事一口气全解决了。
它干的事情一句话就能讲清楚：在完全不动 WorkBuddy 官方安装包的前提下，把一个增强面板注入到正在运行的客户端里。装完之后，WorkBuddy 右下角会多出一个机器人按钮，点开就是 WorkDaddy 的控制面板——账号、主题、会话、模型、增强、自动化、电脑等九个标签页，所有增强功能都从这里进出。
可能有人担心：往官方程序里"注入"，会不会把客户端搞坏？我把原理扒了一遍，只说两点让你安心。
其一，它用的是 Chrome DevTools Protocol（CDP）注入，通俗讲就是让 WorkBuddy 带着调试端口启动，再把界面组件塞进去。官方程序一个字节都没改，签名原封不动，所以官方升级之后，只要界面没有大改，它照常能用。
其二，整个项目以 AGPL-3.0 协议开源在 GitHub 上，截至发稿已经 700 多颗星，账号备份和所有配置全部留在本机，这点后面细说。

03

03｜多账号党狂喜：切号再也不用扫码
先说我最有感觉的账号管理。WorkDaddy 会把每个账号的登录信息独立备份在本机，切换账号就是列表里点一下的事，两秒完成，不用扫码、不用退登录。三个账号来回横跳的日子，就这么结束了。
更爽的是「登录新账号」功能：不用退出当前账号，直接在浏览器里完成 OAuth 授权，扫码之后新账号自动加入列表。老账号还在后台稳稳跑着，全程无感。
还有个功能对多设备党是刚需：账号导入导出。所有账号可以用 AES-256-GCM 加密打包成一个文件，拷到新电脑，装好 WorkDaddy 一键导入。我办公室和家里两台电脑来回切换，再也没出现过"这套账号只在这台机器上有"的尴尬。


04

04｜通宵挂机三件套：免打扰、自动续接、防休眠
接下来是我心中 WorkDaddy 最值钱的部分，也是标题里"AI 通宵替我打工"的底气。三个功能凑成一套组合拳，专门治我"半夜翻车"的场景。
第一件：权限弹窗免打扰。在「增强」页开启之后，那些"是否允许访问文件""是否执行命令"的弹窗全部自动放行，真正的零决策弹窗。你只管睡觉，它自己点"允许"。
第二件：异常中断自动续接。AI 回复因为网络波动、请求超时中断的时候，它会自动让任务接着跑，不用你半夜爬起来救场。
第三件：防止电脑休眠。睡前勾一下禁止休眠，任务跑完之后它还会自动把休眠设置改回来，不至于为了一批任务让电脑空转一整晚。
三件套一起开，我开头那个场景就是另一番景象：任务一路绿灯跑到天亮，早上起来结果已经躺在会话里了。这种"睡前派活、睡醒收货"的体验，用过就回不去。

05

05｜自动化任务：把重复劳动彻底外包
「自动化」Tab 解决的是另一类问题：那些每天都要来一遍的重复操作。
任务的触发方式很全，支持手动运行、事件触发（客户端启动、打开面板、账号切换时）和定时触发（按间隔、每日、每周、每月、指定时间）。我最常用的是它自带的自动领每日积分：多账号每天自动签到，领完缓存状态，完全不打扰你。以前每天早上睁眼先挨个点签到，现在这事跟我没关系了。
创建任务还有个很妙的玩法：支持自然语言描述，直接选「让 WorkBuddy 帮我创建」，它会在新会话里帮你把任务生成好，完成后自动加入列表。也可以自己编辑步骤 JSON，任务支持导出成 JSON 或 ZIP，批量分享给同事用。

06

06｜小功能不多，但个个真香
剩下几个功能单拎出来都不大，合在一起就是"用过就回不去"系列。
暂存提示词是我最近用得最狠的：写到一半的草稿——文字、图片、文件、引用全都原样保留——一键暂存到待发送队列，想清楚再发，或者攒到某个时间点一起发。以前手滑发出半截 prompt 的尴尬，彻底绝迹了。快捷短语则是把常用话术存进面板，输入框旁一键点发，回复客户、写日报这类高频话术再也不用打字。
跨账号会话迁移也值得一提：A 账号里的会话可以复制到 B 账号接着聊，换个模型继续接龙，不用把上下文重新复述一遍。另外还有毛玻璃主题和多套预设壁纸，支持自定义壁纸，颜值党可以放心折腾。


07

07｜怎么装？会不会翻车？
安装很简单。Windows 用户去项目 Releases 页下载安装包，双击装完就能用；macOS 用户下载 dmg 拖进应用程序文件夹，第一次打开如果被拦，去「系统设置 → 隐私与安全性」点"仍要打开"就行。都支持国内版和国际版两个客户端，注意下载对应的包。
最后说点实在的，帮你把预期管理好。
好消息是它没有修改官方安装包，客户端该怎么升级还怎么升级；数据全部留在本机，错误诊断默认开启但可以在「关于」页一键关闭，隐私边界写得明明白白。但要心里有数的是：定时任务和自动化需要 WorkDaddy 的后台服务保持运行，电脑关机了自然就不跑了；另外这类第三方增强项目与官方没有任何隶属关系，属于社区爱好者作品，要不要在主力账号上用，你自己掂量。
