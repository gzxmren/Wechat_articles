Obsidian 装上 Git 和 Claude：笔记库直接进化成"会写代码的笔记本"

Obsidian 一直被称为"最强大的本地笔记软件"，但它真正的上限，取决于你给它装了什么插件。

今天重点聊两个方向的插件：Git（版本控制）和Claude（AI 协作者）。

装上它们之后，你的笔记库会变成什么样？

每一次修改都有"存档"，随时回滚

说一句话，AI 就能帮你改笔记、写总结、画思维导图

甚至把 Claude Code 直接"请进"笔记库，像操作代码一样操作笔记

没错，笔记软件从此有了"工程化"和"智能化"两条腿。

一、先认识一下主角：Obsidian

在聊插件之前，30 秒复习一下 Obsidian 的核心：

本地优先：所有笔记都是纯 Markdown 文件，数据永远在自己手里

双向链接 + 关系图谱：笔记之间互相引用，形成"第二大脑"

强大的社区插件生态：几千款插件，从美化到自动化应有尽有

而插件，正是 Obsidian 拉开其他笔记软件一个身位的关键。

今天的主角：Git 插件管"版本"，Claude 插件管"智力"。

二、插件一：obsidian-git——给笔记库装上"时光机"

先说最刚需的：版本控制。

仓库：Vinzent03/obsidian-git｜Star：1.19 万+｜协议：MIT

1. 它解决了什么痛点？

用 Obsidian 久了，你一定遇到过：

手滑删了一段重要笔记，Ctrl+Z 也救不回来

想在多个设备间同步，但又不想把数据交给第三方云

想看看某篇笔记"昨天长什么样"

obsidian-git 把 Git 的能力搬进 Obsidian，全部在软件内完成，不用碰命令行。

配合Version History Diff插件，可以查看单个文件的完整修改历史

⚠️ 注意：移动端支持目前不稳定（官方明确标注 Highly unstable），主力还是桌面端。

三、插件二：Claudian——把 Claude Code 请进笔记库

如果说 obsidian-git 是"工程化"，那 Claudian 就是"智能化"的标杆。

仓库：YishenTu/claudian｜Star：1.5 万+｜上过 Trendshift 热榜

1. 它是什么？

一句话：把 AI 编程智能体（Claude Code、Codex、Grok、OpenCode、Pi 等）直接嵌入 Obsidian。

你的整个笔记库，就是 AI 的工作目录——读文件、写文件、搜索、跑命令，全部开箱即用。

2. 核心玩法

Inline Edit（行内编辑）：选中文字按快捷键，AI 直接改，逐词级差异预览

斜杠命令与技能：输入 / 或 $ 调用提示词模板和 Skills

@提及：输入 @ 引用笔记库文件、子智能体、外部目录

Plan Mode（计划模式）：Shift+Tab 切换，AI 先勘察、出方案，你批准后才动手

MCP 服务器：通过各智能体的 CLI 配置接入外部工具

Collab Mode（实验性）：与队友在局域网协作同一项目

3. 环境要求

需要已装好至少一个 CLI：Claude Code / Codex / Grok Build / OpenCode / Pi

需要对应的订阅或 API：官方渠道，或OpenRouter、Kimi、GLM、DeepSeek等兼容服务

仅桌面端（macOS / Linux / Windows），Obsidian v1.13.0+

4. 隐私说明

数据只发送给你选择的API 提供商

无遥测、无后台偷偷上传

Collab 模式的项目数据仅在局域网内设备间传输

一句话：Claudian = 在笔记软件里，拥有一个能"干活"的 AI 工程师。

四、插件三：obsidian-skills——Obsidian CEO 亲自下场

这个必须单独说，因为作者是kepano（Steph Ango），Obsidian 官方 CEO。

仓库：kepano/obsidian-skills｜Star：4.76 万+（全站最火的 Obsidian 技能包）

1. 它是什么？

一套遵循Agent Skills 规范（agentskills.io）的技能包，Claude Code、Codex、Open Code 通用，教 AI 正确使用 Obsidian 的各种语法。

2. 内置 5 个技能

技能
作用
obsidian-markdown
正确生成双链、嵌入、Callout、属性等Obsidian 专属语法
obsidian-bases
创建和编辑 .base 数据库文件（视图、筛选、公式）
json-canvas
创建和编辑思维导图 .canvas 文件
obsidian-cli
通过 Obsidian CLI 操作笔记库、开发插件主题
defuddle

3. 安装方式（三选一）

#方式一：插件市场命令   /plugin marketplace add kepano/obsidian-skills      /plugin install obsidian@obsidian-skill# 方式二：npx 安装npx skills add git@github.com:kepano/obsidian-skills.git# 方式三：手动（Claude Code）# 把仓库内容放进笔记库根目录的 /.claude 文件夹  

为什么重要？AI 直接操作笔记库时，经常生成"语法不对"的笔记——比如双链写错、Callout 格式错误。这套技能包就是给 AI 的"Obsidian 语法说明书"。

五、更多值得一试的 Claude 生态插件

Copilot for Obsidian（7.6K Star）：笔记库里的 AI 聊天助手，支持 Claude 等多模型，还能基于笔记内容回答

Smart Connections（5.4K Star）：本地嵌入模型做语义搜索，找相关笔记像"联想"一样自然，零配置免 API Key

Text Generator（2K Star）：用 Claude 等模型在笔记里批量生成内容

claude-obsidian（14.5K Star）：把笔记库变成"自组织 AI 第二大脑"，喂进任何资料，Claude 自动整理

六、组合拳：一个完整的工作流

把上面串起来，你的 Obsidian 可以这样工作：

写作：用 Copilot / Claudian 起草、润色笔记

整理：obsidian-skills 保证 AI 生成的语法完全正确

追踪：obsidian-git 自动提交每次改动

同步：推送到 GitHub 私有库，多端无感同步

回滚：改坏了？一键回到任意历史版本

本地存储 + 版本控制 + AI 协作者 = 真正属于你的"第二大脑"。

七、写在最后

Obsidian 的哲学一直是：你的数据，永远是你的。

Git 插件，让"永远是你的"多了一层安全感（改不坏、丢不了）

Claude 插件，让"第二大脑"第一次有了生产力（不只存，还能干）

如果你还在把 Obsidian 当"高级记事本"，是时候装上这两个方向的插件了。

一个能回滚、能思考的笔记库，值得每个知识工作者拥有。
