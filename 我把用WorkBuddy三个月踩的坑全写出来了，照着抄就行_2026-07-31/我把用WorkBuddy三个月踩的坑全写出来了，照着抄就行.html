一、装完Skill之后，先做这三件事


大部分人装完Skill就开始用，然后发现"好像没那么神"。不是Skill不行，是少了几步准备。

1. 重启一次WorkBuddy

安装Skill之后，WorkBuddy需要重新加载技能列表。有时候你刚装完就能用，有时候不行——取决于加载时机。

我的建议：装完关掉WorkBuddy，等五秒，重新打开。这一步能解决80%的"装了但没反应"的问题。

别嫌麻烦。跟"用了半天发现技能根本没加载上"比起来，重启五秒不算什么。

2. 在技能页面确认状态

打开左侧菜单的"技能"页面，找到你刚装的Skill，看一眼是不是"已启用"状态。

有一次我装了humanizer-zh，用的时候没反应，折腾了半小时才发现——技能装上了，但不知道什么时候被手动关掉了。从那以后我养成习惯，装完必看一眼状态。

3. 先跑一个测试指令

别上来就干正事。先用一个简单的指令测试技能是否正常工作：

  • pptx
    帮我做一个3页的测试PPT，随便什么内容
  • xlsx
    帮我建一个3行2列的测试表格，随便填点数据
  • humanizer-zh
    检测这段话的AI痕迹：人工智能正在改变我们的生活方式，不仅提高了效率，更带来了前所未有的机遇。
  • agent-browser
    打开百度搜索"今天天气"，把搜索结果前3条的标题告诉我
  • mindmap
    把"一周工作计划"做成思维导图
  • pdf-tools
    把这段文字保存成PDF：这是一段测试文字


每个Skill花十秒跑一遍。能正常返回结果，说明没问题。如果报错或者没反应，先解决再干活——别带着问题上路。

二、六个Skill的黄金指令模板


前六篇文章里我给过很多指令，但散落在不同文章里，格式也不统一。这篇我把每个Skill经过反复调试、效果最好的指令模板整理出来。

这些模板不是随便写的——每个都用了不下二十次，改过好几版，现在这版是我觉得最稳的。

模板1：pptx — 做PPT


为什么这么写：
  • 逐页指定内容（P1 P2 P3...）比"你看着安排"效果好十倍。AI自己安排的页面顺序经常乱，你给明确结构它就不会跑偏
  • "每页不超过50字"这条很关键。不加这条，AI会把每页塞满文字，PPT变成了Word
  • "数据标注来源"这条是我后来加的。有一次做报告被领导问"这个数据哪来的"，PPT上没写，很尴尬

常见翻车点：

  • 页数说"15页"但只出了12页 → 在指令里加"必须满15页，不够的加案例页或数据页"
  • 配色不统一 → 加"所有页使用同一套配色方案，图表颜色与页面主色一致"
  • 数据标错 → 这不是指令能解决的，必须逐页检查（后面坑的部分会讲）


模板2：xlsx — 处理表格

为什么这么写：

  • 用编号列出步骤（12345），AI会按顺序执行，不会漏。如果你写成一段话，它经常只做前两步就停了
  • "附带数据摘要"这条是精华。让AI不光整理数据，还帮你看出关键信息。有时候它发现的点你自己真注意不到
  • "标红"这种格式要求要写明。不写的话，AI只会给你纯数据，你自己还得再排版

常见翻车点：

  • 日期格式不统一导致计算错误 → 指令里必须写"统一日期格式"
  • 数据量太大（几万行）处理慢 → 拆成两步，先说"先删除空行和重复项"，等它做完再说第二步
  • 汇总结果跟手动算的对不上 → 检查是不是有合并单元格或者隐藏行，这些会影响AI的数据识别

模板3：humanizer-zh — 去AI痕迹


为什么这么写：
  • "先给检测报告，再给改写版"这个顺序很重要。直接让它改写，你不知道它改了什么、为什么改。先看报告，你能判断哪些地方确实需要改、哪些是AI过度修改了
  • 列出具体的检测维度，比只说"去AI痕迹"效果好很多。AI对"AI痕迹"的理解可能跟你不一样，你得告诉它具体找什么
  • "像真人写的"不如"口语化"——"像真人写的"太模糊，"口语化"是具体的风格指令

常见翻车点：

  • 改完之后AI痕迹反而更高了 → AI有时候"改写"就是把一种AI味换成另一种AI味。解决方法：改完之后再用检测功能跑一遍，看分数有没有降
  • 改写后丢了数据或关键信息 → 指令里强调"保留原意和数据"，如果还是丢，在检测报告里标注"以下内容不可修改：[具体数据]"
  • 改得太口语，不适合正式场景 → 加一句"保持专业度，口语化但不随意"


模板4：agent-browser — 抓数据

为什么这么写：

  • "如果打不开就跳过并告诉我"这条是血泪教训。有一次抓五个网站，第三个挂了，整个任务卡住了二十分钟。加了这条之后，挂了就跳过，其他照常跑
  • "去重"很重要。有些网站会重复推送同一条新闻，不去重的话你的日报里同一条新闻出现三次
  • "整理成表格"比"整理成列表"好。表格可以直接复制到Excel，列表还得手动排版


常见翻车点：

  • 网站有反爬机制 → 换一个同类网站，或者加"如果遇到验证码，等待10秒后重试一次，仍然不行就跳过"
  • 抓到的内容格式乱 → 加"提取纯文本，去掉HTML标签和广告内容"
  • 速度慢 → 减少网站数量，五个以内最稳。超过五个建议拆成两个任务


模板5：mindmap — 思维导图


为什么这么写：
  • 明确分支数量（"4-6个一级分支"）很重要。不说的话，AI有时候给你两个分支，有时候给你十五个，结构不稳定
  • "二级要点要具体，不要空话"这条能过滤掉80%的废话。不加这条，你会得到一堆"提升效率""优化流程"这种正确的废话
  • "补充内容用不同颜色标注"——这个功能超有用。AI补充的内容不一定准确，用颜色标出来你知道哪些是你给的、哪些是它加的，方便核查


常见翻车点：


  • 导图太扁平（只有两层） → 加"至少三层结构"
  • 分支太多太密看不清 → 加"一级分支不超过6个，二级要点不超过4个"
  • 内容太空 → 把你的原始素材多给一点，AI有素材才会往深了展开

模板6：pdf-tools — PDF处理


为什么这么写：

  • 三个操作一次性说完，省得来回发指令。pdf-tools支持一条指令里做多件事
  • "保留原始排版和表格"必须写明。不写的话，转出来的Word可能丢格式、表格变图片
  • 拆分条件写具体（"每10页一份"），别写"适当拆分"——AI对"适当"的理解跟你不一样


常见翻车点：

  • 扫描版PDF转出来全是图片 → 加"如果是扫描件，先做OCR识别再转换"
  • 表格错位 → 转完后检查表格，错位的话加"表格用标准Excel格式重建，不要用图片"
  • 页码不对 → PDF的页码和实际页码有时候差一页（封面不算），在指令里说清楚"从第几页开始算"


三、我踩过的10个坑


这些坑每个都是用时间换来的。写出来不是诉苦，是让你别再踩一遍。

坑1：PPT数据标错


这是第六篇30分钟挑战里差点翻车那个。pptx生成PPT的时候，图表数据偶尔会标错——不是算错，是数字填到了错误的位置。比如瑞幸和星巴克的市场份额搞反了。

解决： PPT生成后必须逐页检查数据。重点看排名类图表（谁第一谁第二）和百分比图表（加起来是不是100%）。文字偶尔有瑕疵能接受，数据错了是硬伤。

坑2：humanizer-zh改完丢数据


有一次让humanizer-zh改写一篇数据分析文章，改完之后发现一个关键数据从"3100亿"变成了"3000多亿"。意思差不多，但精度丢了。

解决： 在指令里加"以下数据不可修改：[列出所有具体数字]"。或者改完之后自己核对一遍关键数据。

坑3：agent-browser被网站拦截


有些网站有反爬机制，agent-browser访问的时候会被拦截或者要求验证码。

解决： 三个办法——第一，换同类网站，别在一棵树上吊死；第二，在指令里加"遇到验证码等待10秒重试，失败则跳过"；第三，降低抓取频率，别一分钟内访问同一个网站好几次。

坑4：xlsx处理大文件卡死


三万行以上的Excel，一次性让xlsx做五六个操作，有时候会卡住不动。

解决： 拆步走。先说"删除空行和重复项"，等它做完再说"按区域分组汇总"。别贪多，一步一步来比一口气等半天靠谱。

坑5：mindmap导图打不开


有时候mindmap生成的导图文件格式有问题，打不开或者显示不全。

解决： 让它输出成图片格式（PNG），不要用源文件格式。图片格式兼容性最好，手机上也能看。

坑6：自动化任务跑了两天就不跑了


第四篇里我设了每天早上8:30抓新闻的自动化任务。有一次它连续两天没跑，我到工位桌上空空如也。

解决： 检查任务状态——有时候是电脑关机了任务没触发，有时候是任务被自动暂停了。我的做法是在自动化任务里加一句"如果任务失败，通知我"，这样出了问题能第一时间知道。另外，别设得太早——8:30比7:00稳，因为那时候电脑肯定开着。

坑7：pptx生成时间超过预期


正常10-15页的PPT生成大概需要3-5分钟。但有一次生成了20分钟还没出来，最后出来发现做了28页——我说的"20页左右"被理解成了"20-30页"。

解决： 页数写死，别说"左右"。写"正好15页"比"15页左右"靠谱。如果生成超过8分钟还没出来，大概率是页数超了，可以在对话框追问一句"还在生成吗？请控制在15页以内"。

坑8：多个Skill同时调用冲突


有一次我同时发了两个指令——一个让xlsx处理表格，一个让pptx做PPT。结果两个任务互相干扰，xlsx的结果被pptx覆盖了。

解决： 一个一个来。等前一个Skill的任务完成（返回结果了）再发下一个。WorkBuddy能同时处理多个任务，但跨Skill的并发有时候会打架。串行比并行稳。

坑9：humanizer-zh过度修改


有一次改写一篇文章，humanizer-zh把我的专业术语都改成了口语。比如"供应链管理"被改成了"进货出货那些事"。意思对，但在专业文章里不能用。

解决： 在指令里加"保留专业术语不变，只改句式和措辞"。或者加一个"不可修改词汇表"：[供应链管理、SKU、GMV、ROI]这些词原样保留。

坑10：指令太长AI理解偏了


有一次写了一条超长的指令，把所有要求都堆在一段话里。结果AI只执行了前半段，后半段全忽略了。

解决： 指令用编号列表（1. 2. 3.），不要写成一大段。AI对结构化指令的理解能力远好于大段文字。如果你的需求确实很多，拆成两条指令发——第一条做主体，第二条做补充调整。

四、5个隐藏技巧


这些不是坑，是让效率再上一层的小门道。

技巧1：先给背景，再下指令


同样一条指令，加不加背景信息效果差很多。

不加背景：

帮我做一份10页的PPT，主题是Q3销售复盘。

加了背景：

我是电商公司的运营，需要给老板汇报Q3销售情况。核心数据：GMV 1.2亿，同比增长23%，但退货率从8%升到了12%。老板最关心退货率上升的原因。帮我做一份10页的PPT，重点分析退货率问题。

加了背景之后，AI知道你的角色、受众是谁、重点在哪里，做出来的东西针对性完全不同。

技巧2：让AI先出方案，你确认后再执行


做复杂任务之前，先让AI给方案：

我需要做一份行业研究报告，包含市场数据、竞争格局、趋势分析。你先给我一个执行计划——分几步、每步用什么Skill、大概需要多长时间。不要直接开始做，先给我看计划。

看完计划觉得OK，再说"按这个计划执行"。觉得不行就调整。比直接让它干、做完了发现方向错了要高效得多。

技巧3：用"参考这个风格"指定输出风格


AI不知道你想要什么风格，但你给它一个样本它就懂了：

按照这篇范文的风格来写：[粘贴一篇你觉得风格好的文章]。保持同样的语气、句式长度和用词习惯，但内容换成我的主题。

这个技巧在写文案、写文章的时候特别好使。比你在那描述"我要轻松一点但不要太随意专业但不学术活泼但不轻浮"有用一万倍。

技巧4：批量任务用"循环指令"


如果你有十个类似文件要处理，别一个个发指令。写一条循环指令：

我有10份Excel文件需要做同样的处理：删除空行、按日期排序、算月度汇总。

我会依次上传，每上传一份你就处理一份，处理完告诉我结果，我说"下一份"的时候你再等下一个文件。

先从这份开始：[上传第一份]

这样你不用每次都重新写一遍指令，AI也保持了上下文，处理速度更快。

技巧5：生成的成果让AI自己检查


PPT做完、文章写完、表格处理完之后，加一条：

现在请你以"挑剔的审核者"视角，检查一下你刚才生成的成果，列出所有可能存在的问题或不完美的地方。不要修改，只列问题。

AI检查自己的东西比你想的严格。它会列出"第3页数据来源未标注""第7页文字超出边框""结论部分缺少具体建议"这些问题。你拿着这个清单去改，比从头到尾自己找问题快得多。

五、新手第一周实操路线


如果你刚装好WorkBuddy，不知道从哪开始，按这个来：

Day 1：装好三个核心Skill


装完重启，在技能页面确认三个都是"已启用"状态。然后每个Skill跑一遍测试指令（本文第一部分有），确认都能正常工作。

Day 1不要干别的。先确保基础环境没问题。

Day 2：用pptx做一个真任务


别练手了，直接干正事。找一个你这周真的要做的PPT——周报、方案、复盘，随便什么都行，反正是要做的。

用第二部分的pptx黄金指令模板，把你的真实需求填进去。做完之后用"技巧5"让AI自查，然后自己逐页检查数据。

这一天你会第一次直观感受到"10分钟出PPT"是什么感觉。

Day 3：用xlsx处理一个真表格


同样，找一个你手头真实存在的Excel。销售数据、考勤表、库存清单，什么都行。

用xlsx黄金指令模板处理。重点练习"分步走"——先清洗，再计算，再对比，一步一步来，不要一口气堆五个操作。

Day 4：用humanizer-zh改一篇文章


随便找一篇你之前写的文章（或者AI生成的文章），用humanizer-zh的黄金指令模板做一次完整的检测+改写。

重点感受"检测报告"的价值——它会告诉你你的文章里哪些地方有AI味，这个认知比改写本身更有用。看多了检测报告，你以后写东西自然就会避开那些AI痕迹。

Day 5：用agent-browser抓一次数据


找五个你常看的网站，用agent-browser黄金指令模板抓一次数据。可以是新闻、可以是竞品价格、可以是行业数据。

抓完之后用xlsx整理成表格。这就是你最基础的"数据采集→数据整理"管线。

Day 6：串两个Skill


试着把两个Skill串起来用。比如：

  • agent-browser抓数据 → xlsx整理成表格
  • xlsx处理数据 → pptx做成PPT
  • WorkBuddy写文章 → humanizer-zh去痕迹

挑一个你工作里真实需要的组合。你会发现串起来用比单独用效率提升不是加法，是乘法。

Day 7：设一个自动化任务


进入WorkBuddy的自动化页面，设一个定时任务。最简单的：每天早上8:30用agent-browser抓三个网站的新闻，整理成日报保存到桌面。

设好之后你不用管它了。第二天早上到工位，桌面上躺着一份日报——这个瞬间你会真正理解什么叫"离不开"。
