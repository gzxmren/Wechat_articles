项目简介

这是一份覆盖Claude Code全功能、全场景的实战指南，核心是把「Agentic Engineering（智能体工程）」落地到日常开发中。

不是零散的技巧堆砌，而是一套从Vibe Coding（凭感觉编程）到Agentic Engineering（系统化智能体编程）的完整方法论，本质是让开发者掌握「用智能体思维解决复杂开发问题」的能力。

很多开发者把 AI 接入真实项目后，马上就会遇到让人抓狂的瓶颈，这个项目精准打中了这三个痛点：

  • 1.用Claude Code越用越乱

只会简单提问写代码，不知道怎么用子智能体、指令、技能分层管理，上下文越堆越杂，最后AI输出的代码全是漏洞；

  • 2.重复劳动耗时间

每天做的代码审查、定时任务、流程编排等工作，不会封装成指令/技能，每次都要重新写提示词，浪费大量时间；

  • 3.不会组织工作流

想让 Claude Code 完成复杂开发任务，却不知道怎么拆解成「调研→规划→执行→审查→交付」的闭环，最后要么半途而废，要么产出不符合预期。

核心亮点特性

  • 结构化的Agentic Engineering方法论

项目核心是把Claude Code的使用拆解成「智能体（Agents）+ 指令（Commands）+ 技能（Skills）」三层架构，形成了「指令触发→智能体执行→技能支撑」的标准化工作流。

比如做天气编排任务时，先通过/weather-orchestrator指令触发，再由专属子智能体处理，最后调用预设的天气查询技能完成操作，整个过程逻辑清晰，不会出现上下文混乱的问题。

而且所有开发任务都遵循「调研→规划→执行→审查→交付」的闭环，从根源上避免瞎做、漏做。

  • 可直接复用的实战模板与自动化能力

项目提供了子智能体、指令、技能、钩子（Hooks）等全场景的配置模板，比如.claude/agents/下的子智能体模板、.claude/commands/下的指令模板，直接复制就能用；

还内置了自动化能力，比如用/loop实现本地定时监控、/schedule实现云端定时任务，甚至能通过Git Worktrees让多个智能体并行开发，把重复工作全交给AI自动化完成。

  • 横向工作流对比

仓库里并没有闭门造车，而是横向对比了 GitHub 上主流的 10 多套 Claude Code 平台工作流。

它帮你做了一套绝佳的选购指南。比如追求代码质量约束选 Superpowers 方案，追求速度选 Get Shit Done 方案，需要从需求到部署全生命周期管理就看 BMAD-METHOD。看一眼就知道哪套最适合你们团队。

  • 紧跟最新功能趋势

项目同步了Claude Code的最新beta功能，比如无闪烁模式（No Flicker Mode）、自动模式（Auto Mode）、计算机控制（Computer Use）、语音听写（Voice Dictation）等。

还给出了这些新功能的最佳使用姿势，让开发者能第一时间用上前沿能力，比如用Auto Mode自动处理权限审核，减少手动确认的麻烦。

  • 高密度的实战技巧

项目不仅收录了 69 条以上的硬核实战技巧、文章和教程，涵盖如何防止 AI 变傻、如何高效复查 PR等。

快速上手使用

  1. 克隆项目

先把仓库克隆到本地，获取所有模板和配置文件。

  1. 最小上手

先从指令（Commands）入手，复制.claude/commands/下的模板，改成自己常用的工作流（比如代码审查、接口调试），输入/claude调用指令就能用；

  1. 进阶配置

根据需求配置子智能体（Agents），给不同功能（比如前端、后端、测试）分配专属智能体，隔离上下文；

  1. 自动化提效

把高频重复的工作封装成技能（Skills），比如定时生成开发日报、自动审查PR，通过/loop或/schedule实现自动化运行。

写在最后

这份claude-code-best-practice，核心是给AI编程装上「工程化的框架」，让你的开发效率从「单点提效」变成「全流程翻倍」。

建议收藏这份仓库，每次用Claude Code开发前翻一翻，先搭好指令/智能体/技能的框架再动手，远比瞎问瞎写高效得多。不管是单人开发还是团队协作，这套方法论都能让你把Claude Code的价值发挥到最大。
