WorkBuddy可以直接连微信了！一文看懂立刻上手用起来
昨天下午，我在一个行业群里看人吵了两个小时。
从"AI 会不会替代中层"吵到"你们公司报销流程有多离谱"，中间夹杂着三个链接、两张截图、五段语音。散场的时候，群里留下一地碎片，谁也没带走什么。
我把其中 47 条消息长按、多选、转发，目标不是同事，不是文件传输助手——是 WorkBuddy。四十秒后，我桌面上躺着一份 Markdown 纪要：争议焦点三条、被反复提及但未结论的问题两个、群友甩过的链接清单一份、可跟进的联系人四位。清清楚楚。
这事本身不稀奇。稀奇的是这条路径是微信亲手放出来的。
微信给 WorkBuddy 开了一道缝转发、打包、唤起、干活：这一步为什么比它看起来重要？

一、先看功能本体

2026 年 9 月 1 日，WorkBuddy 发布 5.5.0 版本，更新日志里躺着这么一条：
支持通过 macOS 和 Windows 系统分享入口，将微信聊天记录发送到 WorkBuddy，并优化转发内容预览
翻译成人话：你在电脑版微信里，把聊天记录多选、转发、选择"转发到其他应用"，列表里会出现 WorkBuddy，点它，内容就过去了。

它长什么样

转发列表里，WorkBuddy 排在元宝之上，带一个"推广"角标；
首次使用会弹《功能使用须知》，提醒你转发内容可能包含隐私信息；
确认后，微信把你选中的内容打包成一个 zip（形如 聊天记录_20260904_225913.zip）；
系统提示"即将离开微信，打开 WorkBuddy"；
WorkBuddy 桌面端被唤起，输入框里生成一枚"微信聊天记录"胶囊（Chip），标明来源、消息条数、解析状态；
这枚胶囊不会自动发送——你可以先补一句指令，再提交。
官方器文档对机制的描述是：无论 WorkBuddy 当时是未启动、已启动还是在后台运行，从微信侧转发都能正常唤起并接收。此外，官方文档明确写了"在微信或企业微信中把聊天记录转发到 WorkBuddy"——企微这条路也是通的。

看清楚这条线：元宝走的是"读懂"，WorkBuddy 走的是"干活"。 元宝拿到聊天记录，给你一份总结；WorkBuddy 拿到聊天记录，给你一份落地的东西——文件、表格、PPT、网页、跑完的代码。

它为什么能拿到这个位置

不是因为它是腾讯亲儿子。腾讯的亲儿子多了。
因为它自己跑出来了。
腾讯 2026 年 Q2 财报，应用层被点名的是两个名字：AI 办公效率服务 WorkBuddy 和 AI 编程工具 CodeBuddy，二者"实现了突破性的用户增长，在各自的领域里处于中国领先水平"；
易观《2026 年 Q2 中国办公智能体平台市场洞察报告》：WorkBuddy PC 端 6 月访问量突破 2000 万，位居国内同类产品第一，且超过第二、三名访问量总和；
一季度财报口径：按日活跃账户数计，WorkBuddy 已成为中国最受欢迎的效率 AI 智能体服务。
结论很直白：微信给的是位置，位置给的是已经证明自己能接住的那一方。 WorkBuddy 是跑得快的那个。微信不养闲人。

二、怎么操作：四步，外加三个坑

操作步骤

第 1 步｜两端都升到最新
电脑版微信 → 最新版
WorkBuddy 桌面端 → 5.5.0 及以上（写这篇时最新是 5.5.2，侧栏底部能看到版本号）
第 2 步｜在微信里多选内容
电脑版微信里，鼠标长按某条消息的头像，向下拖动即可连续选中；支持文字、图片、视频、链接、文件、公众号文章等各种类型。
第 3 步｜转发 → "转发到其他应用" → 选 WorkBuddy
选中后点转发，菜单里找"转发到其他应用"，列表里点 WorkBuddy（带"推广"角标那个）。首次会弹隐私须知，点确定。
第 4 步｜在 WorkBuddy 里补一句话，发出去
客户端被唤起，输入框里出现那枚胶囊。别直接回车——补一句具体要求，效果差十倍。

三个坑（都是版本坑）

转发列表里只有元宝，没有 WorkBuddy
WorkBuddy 版本太旧
升级到 5.5.0+ 再试
列表里有 WorkBuddy，但点过去跳到了元宝
微信版本太旧
电脑版微信升到最新
胶囊一直显示"解析中"或"解析失败"
zip 打包异常或内容过大
删除胶囊，分批重新转发

一句话记住：两端版本不对齐，你会连到一个错的地方，而且错得悄无声息。三条安全习惯（建议养成）


工作群转发前，先过一遍有没有人名、手机号、金额。 你选中的是"内容"，不是"你的内容"。


第一次别拿重要资料试手。 用一个无关痛痒的群，跑通全流程再说。


产物及时归档。 WorkBuddy 生成的文件在任务产物区，点文件夹图标可定位。别让唯一一份成果躺在聊天记录里。

三、玩法：从"帮我总结"到"替我干完"

大部分人拿到这个功能，第一反应是"总结群聊"。这没错，但这只是把元宝的能力搬了个家，大材小用。
真正的分水岭在于：WorkBuddy 会操作你电脑上的文件。所以喂给它的聊天记录，不该只变成一段文字，该变成一个东西。
下面六个玩法，都是我实际跑通的。

玩法 1｜群聊碎片 → 可执行纪要

适用：项目群、客户群吵了半天，需要落地。
提示词：
这是某项目群的讨论记录。请输出：①已达成的结论（注明依据）；②仍存争议的点（列出正反方）；③待办事项（含责任人与时间，缺失的标"待确认"）；④被提及但未展开的话题。生成一份 Markdown 文件保存到工作区，并在对话里给我 200 字摘要。不要替我拍板任何一个争议点。
关键在最后一句。 不加这句，AI 会好心地"帮你定"，然后你就拿到了一份看起来很整齐、实际上掺了它自己判断的纪要。

玩法 2｜客户需求 → 需求文档 + 原型

适用：销售/运营，客户在微信里零散提需求。
提示词：
这是与某客户的沟通记录。请提炼：①明确需求；②隐含需求（客户没直接说但反复暗示的）；③已承诺的功能与时间点；④风险点（客户预期与我们能力不匹配的地方）。输出一份需求清单 Markdown，并生成一版 HTML 原型页面用于下周对齐。
从聊天记录到可演示的页面，中间不再需要产品经理手抄一遍。

玩法 3｜多群情报 → 选题库

适用：内容从业者、投研、竞品分析。
分几个群分别转发，在同一个任务里堆料：
提示词：
共三段来自不同社群的讨论记录。请交叉分析：①被多个群同时讨论的话题（热度交叉验证）；②各群观点分歧最大的话题（适合做争议型选题）；③出现频率最高的产品/公司/人物。输出一张选题表，含选题名、切入角度、可用的原始素材条数、预估争议度。
这是我认为最被低估的玩法。单个群的噪音没有意义，五个群的共振才叫信号。

玩法 4｜报销/票据 → 结构化表格

把群里散落的发票图片、付款截图一起转发：
提示词：
提取所有图片中的金额、日期、商户、用途，生成 Excel。金额识别不清的单独列一行标"待人工核对"，不要猜。最后一列加"是否疑似重复报销"判断，说明判断依据。

玩法 5｜语音会议的二次加工

微信语音转发过去后，WorkBuddy 会处理转写内容。适合：
提示词：
这是一段会议讨论。请输出：①三段式纪要（背景-讨论-结论）；②所有提到的数字与时间点，单独列表核对；③没有明确负责人的待办，标红。

玩法 6｜接上 Skill，把它变成流水线

这是从"能用"到"好用"的那一跳。
WorkBuddy 内置 20+ 技能包，兼容 OpenClaw 社区技能。你可以先建一个"周报"技能，定义好你们公司的周报模板，然后每周五把这一周的关键聊天记录转发过去，一句话：
调用周报技能，基于这段聊天记录补完本周进展部分。
一次配置，长期复用。 功能的价值不在单次效率，在于能不能被固化成习惯。

四、别着急：这只是"第一道缝"

我知道外面已经有人在写"微信开放生态""AI 接管微信"了。
别急着上价值。这道缝，开得非常有分寸。
边界一：这是系统级出口，不是微信的 API
它走的是 macOS / Windows 的系统分享面板，本质是操作系统原生的"把内容交给另一个应用"的能力。
这意味着三件事：
微信没有开放任何聊天记录数据库，也没有给 WorkBuddy 任何读取权限；
数据是单向的：微信 → WorkBuddy，反向不成立；
全程手动触发，微信不会自动把任何东西推给 WorkBuddy。
对比一下元宝的做法：聊天记录到了元宝，是临时对话，退出即焚，不进入历史。这个设计本身就是腾讯对"聊天记录交给 AI"这件事的态度——能看，但别留。
WorkBuddy 这条路稍有不同（内容会落到你的本地任务目录），但它同样建立在"你主动选、你主动发、你确认须知"的前提上。
边界二：只在电脑上，手机上还不行
目前仅支持电脑版微信 + 电脑版 WorkBuddy。手机端微信转发的列表里，暂时还没有 WorkBuddy。
注意区分另一条路径——微信小程序。那是早已有之的另一回事：WorkBuddy 小程序扫码绑定后，可以在手机上远程遥控电脑端执行任务。机制不同，入口不同，别混为一谈。
而电脑必须开机、WorkBuddy 必须能跑。 转发能唤起客户端，但唤起一台关机的电脑，它做不到。
边界三：隐私红线不会退让
那个《功能使用须知》弹窗不是走过场。腾讯在聊天数据上的克制是出了名的——这是微信的立身之本，也是它最不可能交易的东西。
所以任何"AI 自动读取你所有聊天记录"的想象，在可预见的未来都不会发生。能发生的是：你想给的时候，给得方便一点。
微信没有把家门钥匙给 WorkBuddy。它只是在门上装了个猫眼，并且决定：由你来选什么时候开门、放谁进来。
这个分寸感，恰恰是它值得被认真对待的原因。克制的开放，比激进的开放走得更远。

五、下一步，边界会往哪儿推

我的判断是：这一步的意义不在它本身，在于它验证了"微信内容可以安全出境"这个技术前提。 一旦这条路被证明不出事，后面的想象空间就打开了。
按可能性从高到低，列几个我期待的方向：
🟢 高概率：手机端打通
电脑端跑通了，手机端是顺理成章的下一步。微信 iOS/Android 的分享面板里出现 WorkBuddy，只是时间问题。
一旦手机端打通，使用场景会从"坐在工位整理"变成"随时随地处理"——通勤路上把昨晚的群聊丢过去，到公司纪要已经在桌面上了。
🟢 高概率：从"总结"到"订阅"
现在是你手动转发。下一步可能是：订阅某个群，每天定时自动摘要，推送到微信。
技术上毫无难度（WorkBuddy 的自动化任务早就能定时跑，企业微信机器人的结果推送也已经跑通）。卡点不在技术，在授权——微信愿不愿意让你"长期授权"某个群。
我猜会以一种很克制的方式出现：手动开启、随时可关、明确告知、本地处理。
🟡 中概率：聊天记录成为长期上下文
现在每次转发都是一次性的。但如果 WorkBuddy 能把处理过的聊天记录沉淀进你的个人知识库（它已经有资料库和长期记忆能力了），那就意味着——
你的微信，会成为你的第二大脑的外部硬盘。
三个月前客户提过的一个需求，今天他再提，WorkBuddy 能翻出来告诉你："他上次也提过，当时你说等下一版。" 这个杀伤力，比任何总结功能都大。
🟡 中概率：结果回写微信
现在企微机器人已经能把任务产物推送到企业微信了。个人微信这边，还会远吗？
理想的闭环是：微信转发 → WorkBuddy 干活 → 结果以卡片形式回推微信 → 你直接转发给同事。全程不离开微信。
⚪ 低概率但值得期待：微信生态数据接入
公众号后台数据、视频号数据、小程序数据、微信支付账单——这些如果能作为上下文进入 WorkBuddy，那就不只是"办公助手"了，是微信生态的操作系统。
这一步很远。涉及的数据敏感度比聊天记录还高。但反过来说，正因为远，才值得盯。
⚪ 最不该期待的：微信开放聊天数据库
说三遍：不会、不会、不会。
任何指望 AI 自动读你全部聊天记录的期待，都是对微信产品哲学的误读。微信的护城河是信任，信任一旦破，两万亿的盘子会抖。
能期待的是"你主动给的，处理得更好"，不是"你不给的，它自己拿"。

六、写在最后

回到开头那个吵了两小时的群。
以前这类讨论的结局是：你记得个大概，然后忘了。散落的信息像水一样蒸发，唯一留下的是一种模糊的"好像聊过什么"的感觉。
现在你可以让它留下来，变成一份能被检索、被执行、被追问的东西。
这背后是一个更大的变化：AI 的能力边界，正在从"模型有多聪明"迁移到"它能触达多少上下文"。
模型大家都能买到，DeepSeek、GLM、Kimi、混元，摆在货架上任挑。真正拉开差距的，是谁手上有别人拿不到的上下文。
而对中文世界来说，最大的那块上下文，就在微信里。
微信肯开一道缝，是因为它知道：缝的另一边站着的，是自己人也接得住的人。
至于这道缝后面会开成门还是窗，取决于一件事——

第一批用起来的人，有没有把这件事做得体面。别拿它去扒别人的聊天记录。别把群里朋友的闲谈当成"素材"。别在未经同意的情况下，把别人的话变成你的报告。技术的开放从来不是单向的。它开多大，取决于配不配得上。现在就更新到 5.5.2，转发一条群聊试试。
