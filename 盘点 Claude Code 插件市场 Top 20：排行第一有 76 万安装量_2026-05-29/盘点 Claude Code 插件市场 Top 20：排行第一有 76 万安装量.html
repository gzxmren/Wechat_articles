盘点 Claude Code 插件市场 Top 20：排行第一有 76 万安装量

我翻了一遍官方插件市场安装量最高的 20 个插件，看完就能判断哪些值得装。

小提示：以下安装命令都是在 Claude code 里输入，而不是终端噢。

安装完一批插件后，在 Claude Code 里输入 /reload-plugins 统一刷新一次。如果插件依赖 SessionStart Hook，最好再开一个新会话。

第 20 名：Pyright LSP

•安装量：85,983
•一句话定位：给 Claude Code 装上 Python 语言服务器，实现代码补全、类型检查和跳转定义
•适合谁：Python 开发者，尤其是写类型标注的项目
•主要能力：提供 Pyright/Pylance 级别的 Python 类型检查和语言智能，包括自动补全、定义跳转、错误提示
•安装命令：/plugin install pyright-lsp@claude-plugins-official
•前置条件：需要安装 pyright（npm install -g pyright 或 pip install pyright）
•典型使用场景：写 Python 项目时自动提示类型错误、跳转函数定义、查看文档
•优点：微软官方维护，类型检查准确度高，和 VS Code 的 Pylance 同源
•限制：只是语言服务器，不包含格式化或 lint 功能；需要额外安装 pyright 二进制
•权限和安全注意事项：LSP 只读取项目文件用于分析，不会执行代码或访问网络

第 19 名：PR Review Toolkit

•安装量：91,694
•一句话定位：一套专门的 PR 审查 Agent 组合，从注释质量、测试覆盖、错误处理、类型设计到代码简化全覆盖
•适合谁：需要做 Code Review 的开发者，尤其是团队中有 PR 审查流程的人
•主要能力：6 个专项 Agent 各管一摊：comment-analyzer 分析注释、pr-test-analyzer 检查测试、silent-failure-hunter 找静默失败、type-design-analyzer 审类型设计、code-reviewer 查代码质量、code-simplifier 简化代码
•安装命令：/plugin install pr-review-toolkit@claude-plugins-official
•前置条件：GitHub CLI（gh）已安装并认证
•典型使用场景：PR 提交后跑一遍全面审查，或者只跑其中一两个检查项
•优点：比通用 Code Review 更细粒度，每个 Agent 有明确分工；可以指定只跑某些检查
•限制：依赖 GitHub CLI；多个 Agent 跑起来耗时较长
•权限和安全注意事项：需要 GitHub token 读取 PR 和仓库信息

第 18 名：Supabase

•权限和安全注意事项：需要 Supabase 访问令牌，能操作数据库和数据，注意权限范围

第 11 名：Ralph Loop

•安装量：168,011
•一句话定位：让 Claude Code 进入自主循环模式，反复迭代直到任务完成，你人可以走开
•适合谁：有明确验收标准的开发任务，尤其是需要反复调试和修复的场景
•主要能力：通过 Stop Hook 拦截会话退出，把同一个 prompt 反复喂给 Claude Code，每次迭代都能看到上一次的修改结果，直到任务完成或达到最大迭代次数
•安装命令：/plugin install ralph-loop@claude-plugins-official
•前置条件：无
•典型使用场景：/ralph-loop "修好所有失败的测试" --max-iterations 20 --completion-promise "DONE"，然后去做别的事
•优点：真正的自主循环，不需要你在旁边盯着；适合绿场项目和边界清晰的任务
•限制：不适合需要人工判断的任务；任务描述要写得足够清晰；没有设置 max-iterations 的话可能无限循环
•权限和安全注意事项：自主模式下 Claude Code 会持续编辑文件和执行命令，确保任务边界清晰

第 4 名：Code Review

第 3 名：Context7

•安装量：328,453
•一句话定位：实时拉取最新版本文档和代码示例进 Claude Code 上下文，解决 AI 训练数据过时导致的幻觉 API 问题
•适合谁：几乎所有开发者，尤其是经常用各种框架和库的人
•主要能力：通过 MCP 服务器从源码仓库拉取版本匹配的文档和代码示例。两个核心工具：resolve-library-id（匹配库名到 Context7 ID）和 query-docs（按问题检索文档）。支持指定版本号
•安装命令：/plugin install context7@claude-plugins-official
•前置条件：需要 Context7 API 密钥
•典型使用场景：写代码时说「Create a Next.js middleware that checks JWT in cookies」，Context7 自动拉取 Next.js 最新版本文档，保证生成的代码用的是当前 API
•优点：解决了 LLM 训练数据过时这个根本痛点；自动触发，不需要每次手动指定；支持版本锁定
•限制：依赖 Upstash 的托管 MCP 服务器（mcp.context7.com），查询时库名和代码会离开本机；免费版有调用次数限制
•权限和安全注意事项：库名和查询代码会发送到 Context7 服务器；不建议在查询中包含敏感代码

第 2 名：Superpowers

•安装量：681,792
•一句话定位：一套完整的软件开发方法论框架，教 Claude Code 按 TDD、系统调试、Socratic 头脑风暴等规范流程工作
•适合谁：追求工程纪律的开发者，尤其是团队协作场景
•主要能力：14 个可组合技能覆盖完整开发流程：brainstorming（Socratic 式需求探索）、writing-plans（拆成 2-5 分钟的小任务）、execute-plan（批量执行加审查检查点）、debugging（四阶段系统调试法：根因调查→模式分析→假设测试→实现，三次失败后触发架构审查）、TDD（red-green-refactor 循环），以及 git worktrees、code review、skill 编写等
•安装命令：/plugin install superpowers@claude-plugins-official
•前置条件：无（安装后需重启会话以激活 SessionStart Hook）
•典型使用场景：开始一个新功能时 /brainstorming 先探索需求，然后 /writing-plans 拆任务，/execute-plan 批量执行
•优点：把「想到哪写到哪」变成有纪律的工程流程；社区活跃（20 万 GitHub Stars），持续更新；兼容 Codex、Gemini CLI、Cursor 等多个 AI 编程工具
•限制：SessionStart Hook 每次启动注入约 1300-1500 token，即使不用 Superpowers 技能也会消耗上下文；学习曲线存在
•权限和安全注意事项：Hook 在会话启动时自动运行；技能执行时会编辑文件、执行命令

第 1 名：Frontend Design

•安装量：760,428
•一句话定位：让 Claude Code 生成有设计感的前端界面，而不是千篇一律的「AI 味」UI
•适合谁：前端开发者、全栈开发者、任何需要做 UI 的人
•主要能力：50 种设计风格、21 套配色方案、50+ 字体搭配，覆盖 React/Next.js/Vue/Svelte/Tailwind/shadcn/ui 等多框架。写前端代码时自动调用，避开 Inter 字体、紫色渐变、常规布局等「AI 审美」
•安装命令：/plugin install frontend-design@claude-plugins-official
•前置条件：无
•典型使用场景：任何前端任务自动触发，生成出来的 UI 不会一眼就看出是 AI 写的
•优点：解决了 AI 生成前端最大的痛点——所有页面都长一个样；自动触发无需手动调用；Anthropic 官方出品并标注 Verified
•限制：自动触发意味着做 UI 任务时它总会干预，如果你就是想要默认风格反而需要额外说明；不参与后端逻辑
•权限和安全注意事项：只影响前端代码生成，不涉及数据或网络
