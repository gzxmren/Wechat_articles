安装 dsh 教程

注意截止至目前（2026.9.6）dsh仍为实验性的开发者预览软件。它尚未接受安全审计，不得视为安全或可用于生产环境的软件。

dsh：这是什么？

大家常说的 dsh，全名是 DeepSeek Harness。简单理解，它是在你自己电脑上运行的 AI 助手工作台，装好后就能和 DeepSeek 一起写代码、处理任务。

放心，它不要求你懂编程。只要照着下面的步骤，一步步点下来就能装好。

开始前，你只需要三样东西：

  1. 一台 Windows 电脑（Win10 / Win11 都行）
  2. 能上网（国内网络直接就能用，不用翻墙）
  3. 一个 DeepSeek 账号（用来拿 API Key，后面会说，先跳过也完全没问题）

第一部分 ｜ 先装 Node.js（dsh 的「发动机」）

dsh 是靠 Node.js 运行的，所以第一步得先把 Node.js 装上。这一部分就是给后面打基础，装好之后剩下的步骤基本是自动的。

第 1 步 ｜ 打开浏览器（推荐用自带的 Edge）

在桌面上找到 Microsoft Edge 图标，双击打开。用别的浏览器（谷歌 Chrome、火狐）也都一样。

第 2 步 ｜ 打开 Node.js 官网

先把浏览器最上面的网址栏清空，输入 https://nodejs.org/zh-cn，按回车。

要是懒得敲网址，直接在搜索框搜「Node.js」，点第一个带 nodejs.org 的链接进去也一样。

第 3 步 ｜ 下载 Node.js 安装包

进到官网后，找到绿色的 获取 Node.js® 或 下载 Node.js 按钮点进去，就到了下载页。在这一页直接点绿色的 Windows 安装程序(.msi) 按钮，电脑就自动开始下载了。

第 4 步 ｜ 找到下载好的安装包

下载很快（就几十 MB），一会儿就好了。去「下载」文件夹里，你会看到一个名字类似 node-v24.20.0-x64.msi 的文件，这就是我们刚下的安装包。

第 5 步 ｜ 双击运行安装包

双击这个安装包，就会弹出 Node.js 的安装向导。第一次见面，什么都不用管，直接点右下角的 Next（下一步）。

第 6 步 ｜ 同意协议

这一页是使用协议。找到 I accept the terms in the License Agreement（我接受协议条款），把前面的小方框勾上，然后继续点 Next** 就行。

第 7 步 ｜ 修改存储位置

这一页问你要把 Node.js 装到哪。一般情况下保持默认就行；想改就点 Change… 换个文件夹，然后点 Next。

第 8 步 ｜ 附加工具（这一步切记，别乱勾）

这一页问你要不要额外装一些编译工具。新手千万别勾，保持那一项空着，直接点 Next 就对了。

⚠️ 重点提醒： 千万别勾选 Automatically install the necessary tools... 那一项！一旦勾上，安装会弹出黑窗口自动装一大堆东西，又慢又容易出问题。

第 9 步 ｜ 开始安装

最后确认页，点右下角蓝色的 Install（安装），然后耐心等进度条走完（很快，一两分钟）。

第 10 步 ｜ 验证是否装好

装好了还不算完，咱得确认一下。按键盘上的 Win+R（Win 键是左下角那个带四个格子的图标），会弹出「运行」小窗口，在里面输入 cmd，点击确定，就会打开一个黑色小窗口。

在黑色窗口里，依次输入下面两行，每输一行按回车：

node -v npm -v
  • 输入 node -v → 会出现 v24.20.0
  • 输入 npm -v → 会出现 11.19.0

只要能看到这些版本号，就说明 Node.js 装好了，可以放心进行下一步。

第二部分 ｜ 安装 dsh 本体（一条命令搞定）

第 11 步 ｜ 复制这条安装命令

还是在刚才那个cmd窗口里。把下面这一整行复制下来，粘贴进去，按回车：

npm install -g @deepseek-ai/dsh && dsh web

按回车后会自动开始下载安装，大概要几分钟，期间会滚动一大片英文字母。不用担心，耐心等它跑完就行。

第 12 步 ｜ 等到出现「http://127.0.0.1:3080」

当你看到屏幕上出现 dsh web: http://127.0.0.1:3080/?token=... 这样一行网址时，就说明 dsh 已经成功启动了，浏览器会自动帮你打开它。

第 13 步 ｜ 以后想用就输入「dsh web」

以后想再打开 dsh，不用重新装，只要再开一个黑色窗口，输入 dsh web 回车，它就会自动生成网址并打开浏览器。

第三部分 ｜ 首次使用 dsh（照着点）

第 14 步 ｜ 阅读内测声明

浏览器会自动打开 dsh 的页面（网址是 127.0.0.1:3080）。第一次进来会看到一份「内测声明」，直接点右下角的 继续 按钮进去就行。

第 15 步 ｜ 添加 API Key

接下来它会问你要不要填一个 API Key。要是只想先看看界面，直接点 稍后配置 跳过；想真正用起来，就点 保存并继续。下面的「附录」会教你如何拿到这个 Key。

第 16 步 ｜ 看到这个界面就装好了

当你看到「探索未至之境」这个主界面，就说明 dsh 装好了，可以开始使用了。

附录 ｜ 想正式用起来？教你如何拿 API Key

上面第 15 步的「保存并继续」需要一个 API Key。它相当于给 AI 的「钥匙」，有了它 dsh 才能叫得动 DeepSeek 模型。

第 17 步 ｜ 打开 DeepSeek 开放平台

在浏览器输入 https://platform.deepseek.com 回车（或者先去 deepseek.com 官网点「API 开放平台」）。

第 18 步 ｜ 创建你的 API Key

登录并完成实名后，在左侧菜单找到 API keys，点进去，再点右上角的 创建 API key。随便起个名字，比如 dsh，然后 点【创建】，它就会生成一大串字符，你把这串字符完整复制下来。注意这个Key只会显示一次，如果忘记密钥就只能重新创建一个Key了。

拿到 Key 之后，回到 dsh 的第 15 步，把这串字符粘贴到「输入 API 密钥」框里，点 保存并继续 就可以了。

❓ 常见问题（遇到卡壳看这里）

Q1：提示「npm 不是内部或外部命令」

说明 Node.js 没装好。回第一部分按步骤重新装一遍，装完一定要用 node -v 验证出结果再往下走。

Q2：浏览器没自动打开，或网址打不开

dsh 的网址固定是 http://127.0.0.1:3080。把cmd窗口里那行完整网址复制到浏览器打开就行。

Q3：安装时英文一大堆看晕了

正常现象，不用管。只要最后出现 http://127.0.0.1:3080 这一行，就说明成功。

Q4：想备份 / 换电脑 / 重装？

把上面所有步骤再走一遍就行，命令和操作完全一样，记不住就回来翻这份教程。

到这里，dsh 就安装成功了。
