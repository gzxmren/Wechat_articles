WorkBuddy 积分耗尽，不充会员也能继续用
很多小伙伴用的这些“小龙虾”工具，多少都开始收费了吧，我们公司用 WorkBuddy比较多，5 月份就没什么免费积分领取了，并且发现，好像积分的消耗也更快了。

会员，目前个人专业版，每月 58 元，只有 2000 积分吧，不算便宜了，对公司来说，也不是很好管理。

所以，我们调整了个方案，费用公司买单，使用“自定义配置模型”的方法，不单单是 WorkBuddy，其他的，比如 QClaw、Marvis，等等，都可行的。

目前接入了 DeepSeek-V4，我对比了下同样的任务，使用 DeepSeek-V4，不管是 Pro 版，还是 Flash 版，扣除的 token 费用，对比 WorkBuddy 的积分费用，至少得低了 5 倍吧。

并且单纯的充值会员，不是太方便公司管理，公司维度对 AI 买单，还是要统一管理 token 会比较合适，每个人给到对应的 api key，也能检测使用情况。


操作流程（以接入 DeepSeek-V4大模型为例）：

1.注册deepseek开放平台，https://platform.deepseek.com/

2.在“个人信息”，进行“实名认证”，选择“企业认证”，因为如果是个人的，你的api key是不能同时给多人使用的，只有企业认证的才可以。

3.在“API keys”，选择“创建 API key”，一定要记录好，复制了之后，这里就不再显示了。

4.要先充值，这个是根据使用扣费的，如果需要报销，开发票，是可以根据“充值金额”开发票的，也可以退款，这个很友好。

5.另外，这里是可以检测用量的，还可以设置余额的预警。

6.打开 WorkBuddy，对话框，点击“Auto”，“配置自定义模型”，提供商选择“深度求索/DeepSeek”，输入上面的“API key”，选择对应的模型，点击保存。

7.然后要退出 WorkBudyy，重新打开，在对话框的“Auto”这里，选择刚才配置好的 DeepSeek-V4 的大模型，就可以使用了。

8.后面就只会扣你 deepseek 开放平台账户的钱了，WorkBuddy 的积分就不再消耗了，也就是不需要充值会员了。
