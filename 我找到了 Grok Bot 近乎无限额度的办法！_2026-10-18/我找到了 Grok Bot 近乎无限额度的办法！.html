我找到了 Grok Bot 近乎无限额度的办法！

这两天玩 Grok Bot 有点上头，30 刀/月的套餐周额度已经用完了 84%，得找个办法续命了。于是，发动智慧树，我找到了 Grok Bot 近乎无限额度的办法。🏄

其实 Grok Bot 有自己的一台 Linux 电脑，能装软件、能跑命令。于是，思路就有了：直接让它装上开源的 Pi Agent，再填入自己的 DeepSeek 或 MiniMax API Key。
你只要在聊天里用大白话说需求，剩下的它自己搞定。下面全程不用你敲一行命令，复制粘贴发过去就行。
1️⃣ 第一步：让 Grok Bot 装 Pi Agent
直接发这句：
> 帮我装 Pi Agent
2️⃣ 第二步：说清楚你接哪家模型
Pi 自带 MiniMax 支持，Key 只在对应区域能用。发这句：
> 我要接 MiniMax，国内版的
想用 DeepSeek，把名字换掉就行，流程一模一样。
3️⃣ 第三步：把 Key 填进去
> 接下来我给你 API Key，你引导我填进去
Grok Bot 会弹出一个加密输入框：Key 不会出现在聊天记录里，它自己也看不到明文。实测它还会自动试国内版和海外版，判断你的 Key 属于哪个区域。
4️⃣ 第四步（可选）：指定具体模型
比如 MiniMax-M3.1-Flash-Preview，Pi 自带列表里没有（只有 MiniMax-M2.7 和 M2.7-highspeed），但没关系：
>用 MiniMax-M3.1-Flash-Preview，Pi 自带列表里没有，你手动加上并设成默认。
然后跑一句测试确认能正常回复。
5️⃣ 第五步：立规矩
> 以后每次开始新任务前，先问我用 Pi + MiniMax 还是你自己做
它会记住，之后每次弹一个选择卡片给你选。
我实测接入 MiniMax-M3.1-Flash，整理 X 科技热点、撰写广州商场分析报告，几秒到十几秒出稿，Grok Bot 还会逐条核对来源，把模型瞎编的内容剔除。
