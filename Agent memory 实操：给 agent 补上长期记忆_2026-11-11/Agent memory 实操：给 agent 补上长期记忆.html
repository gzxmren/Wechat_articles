Agent memory 实操：给 agent 补上长期记忆

 


AI agent 会推理，会调工具，能完成复杂任务。但它有个通病：会话一结束，之前的一切全忘——每开一个新对话，都像从零开始。

Agent memory（智能体记忆）要解决的就是这件事。它让系统跨会话留住有用的信息：你的偏好、之前拍板的决定、目标，还有那些重要的上下文。

下面用 OpenAI Agents SDK 和 Mem0 搭一个有长期记忆的 agent。搭完之后，再把同一套记忆接到 OpenCode 上，让编码 agent 也能跨会话记事。

记忆是怎么跑起来的

最简的循环长这样：用户发一条消息，agent 去记忆里搜相关上下文，带着搜到的内容推理，然后把有用的部分存回去。

记忆分两类：

  • • 短期记忆：当前这轮对话或任务里的信息，比如最近几条消息、临时状态。
  • • 长期记忆：跨会话留得住的，偏好、决策、目标、以往的经历。

关键在检索。不是把历史对话一股脑塞进 prompt，而是搜一遍，只捞回跟当前请求相关的那几条。上下文小了，行为上却仍然像"记得"。

动手：一个有长期记忆的 agent

先装两个包：

pip install openai-agents mem0ai

配好 API key：

export OPENAI_API_KEY="your-openai-key"
export MEM0_API_KEY="your-mem0-key"

导入需要的类，建一个 Mem0 客户端：

from agents import Agent, Runner, function_tool
from mem0 import MemoryClient

memory = MemoryClient()
USER_ID = "abid"

MemoryClient 是通往 Mem0 的入口；USER_ID 告诉 Mem0 这些记忆属于谁。每个用户一个独立标识，记忆就互相隔离。

搜索工具

给 agent 一个查历史的手段：search_memory 把当前 query 发给 Mem0，取回最相关的几条。

@function_tool
def search_memory(query: str) -> str:
    """Search for relevant memories about the user."""

    results = memory.search(
        query=query,
        filters={"user_id": USER_ID},
        top_k=5,
    )

    memories = results.get("results", [])

    if not memories:
        return "No relevant memories found."

    return "\n".join(
        f"- {item['memory']}"
        for item in memories
    )

Mem0 走的是语义搜索，措辞不必对上。意思接近，照样能捞到。

写入工具

save_memory 负责把事实、偏好、决定写进 Mem0。

@function_tool
def save_memory(content: str) -> str:
    """Save useful long-term information about the user."""

    memory.add(
        messages=[
            {
                "role": "user",
                "content": content,
            }
        ],
        user_id=USER_ID,
    )

    return "Memory saved."

Mem0 会自己处理这段内容，只把其中有用的部分存成长期记忆，而不是把整段对话打包扔进去。

组装 agent

agent = Agent(
    name="Memory Assistant",
    model="gpt-5.6-luna",
    instructions="""
    You are a personal assistant with long-term memory.
    Always call search_memory before answering, even for general questions.
    When a relevant memory is found, acknowledge it naturally at the start,
    for example: "Oh, I remember you prefer...", then use it.
    Save durable preferences, goals, and facts; confirm each save in one
    sentence. Skip greetings, temporary info, and duplicates.
    """,
    tools=[
        search_memory,
        save_memory,
    ],
)

instructions 决定 agent 怎么用记忆：回答前先查；查到了就在开头自然带一句；哪些该存、哪些（寒暄、临时信息、重复内容）该跳过——全写在这里。

外面再包一个 chat()：

def chat(message):
    result = Runner.run_sync(
        agent,
        message,
    )

    return result.final_output

每调用一次，消息进 agent，agent 自己决定要不要动那两个工具。

试一试

先喂一条值得存的偏好：

print(chat(
    "Remember that I prefer Python and use uv "
    "for managing my projects."
))

输出：

I'll remember that you prefer Python and use `uv` to manage your projects.

再问一个相关的：

print(chat(
    "How should I set up my next Python project?"
))

输出：

I remember you prefer Python and use **uv** for project management. A solid setup:

```bash
uv init my-project
cd my-project
uv add <runtime-dependency>
uv add --dev pytest ruff mypy
```

search_memory() 把刚才那条偏好捞了回来，回答因此对得上人。更重要的是，记忆落在 Mem0 里，Python 应用重启之后照样搜得到。

让 OpenCode 共用这套记忆

不写 Python 工具也行。Mem0 提供了官方的托管 MCP（Model Context Protocol）server，带增、查、改、删记忆的一组工具。

装进 OpenCode：

npx mcp-add \
  --name mem0-mcp \
  --type http \
  --url "https://mcp.mem0.ai/mcp" \
  --clients "opencode"

重启 OpenCode，先跟它说一句：

Remember that I prefer uv instead of pip for new Python projects.

再新开一个会话，问：

How should I initialize this Python project?

OpenCode 通过 Mem0 的 MCP 工具取回那条偏好。Mem0 目前暴露的操作有 add_memory、search_memories、get_memories、update_memory、delete_memory 等。

想确认连接是否正常：

opencode mcp list

最后

ChatGPT 的记忆功能干的就是这件事——记住之前对话里的有用信息，下次带回来。所以有时候你话没说完，它好像已经懂了。

自己的 AI 应用里也能做出同样的体验。给客服助手记住客户偏好，给内部工具记住关键决策，给编码 agent 记住你惯用的框架、项目规矩和开发习惯。用户不必每次从零讲一遍，agent 从早前的会话里取回相关信息，回答就更贴合、更一致。
