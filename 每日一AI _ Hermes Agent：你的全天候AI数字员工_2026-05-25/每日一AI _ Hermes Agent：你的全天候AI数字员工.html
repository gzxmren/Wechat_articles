一、Hermes Agent 是什么？

想象一下，你有一个24小时在线的AI助手，它不仅能回答你的问题，还能主动帮你整理文件、写代码、浏览网页、甚至定时自动完成各种任务——这就是 Hermes Agent。
Hermes Agent 是由 Nous Research 团队开发的开源自主AI智能体，定位为"你的AI数字员工"。它最大的特点是**自我进化**：你教它做过的任务，它会自动沉淀为可复用的"技能"（Skills），下次遇到同类任务，直接调用即可，越用越聪明。
**一句话总结**：它是一个能理解你、记住你、越用越聪明的全天候AI助手，支持 Windows(WSL2)、macOS、Linux，还能接入微信、飞书、Telegram 等常用聊天软件。

二、核心功能深度解析

1. 持久化记忆：跨会话记住你的习惯

Hermes 使用 SQLite + FTS5 全文搜索存储你的偏好和项目背景。比如你告诉它"我的代码项目在 ~/projects 目录"，下次你问"看看我的项目进展"，它会自动去那个目录扫描。

2. 自我进化 (Skills)：越用越聪明的秘密

这是 Hermes 最吸引人的功能。当你成功完成一个复杂任务（比如整理发票），它会自动生成一个 Markdown 格式的 `SKILL.md` 文件，记录完整的操作流程。下次你只需要说"照上次那样整理发票"，它就能快速复用。这些技能文件存储在 `~/.hermes/skills/` 目录，你可以随时查看、编辑、分享。

3. 多功能工具箱：40+ 内置工具

Hermes 内置了 40 多种工具，覆盖日常办公的方方面面：
  • 文件操作：读写、移动、删除、搜索文件
  • 代码执行：运行 Python/Shell 脚本
  • 浏览器自动化：自动打开网页、抓取数据
  • 终端命令：执行系统命令
  • 图像生成：调用 Stable Diffusion 等模型
  • Web 搜索：联网获取最新信息
还支持 MCP 协议扩展，可以连接数据库、API 服务等第三方工具。

5. 定时自动化：7x24 小时无人值守

支持自然语言或 Cron 表达式设置定时任务，比如：
  • 每天 9:00 自动备份重要文件
  • 每周一 10:00 抓取指定网站数据生成报告
  • 每小时检查一次邮箱，摘要重要邮件
  • 每月 1 号清理临时文件夹

Windows 用户特别注意

Hermes 不支持原生 Windows，必须使用 WSL2（Windows Subsystem for Linux 2）。安装方法：
  1. 以管理员身份打开 PowerShell，运行：
    wsl --install
  2. 重启电脑，按照提示设置 Ubuntu 用户名和密码
  3. 打开 Ubuntu 终端，继续下面的安装步骤

方案一：一键安装（推荐新手）

这是最简单的安装方式，脚本会自动处理所有依赖：
4.打开终端（Windows 用户打开 WSL2 的 Ubuntu 终端）
5.运行安装命令：
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
6.脚本会自动安装 uv、Python 3.11、Node.js 22 等依赖
7.安装完成后，运行：
source ~/.bashrc（或 source ~/.zshrc）
8.验证安装：
hermes --version
如果看到版本号（如 v0.12.0），说明安装成功。

方案二：手动安装（适合开发者）

如果你需要更多控制，可以手动安装：
  1. 安装 uv（Python 包管理器）：
    curl -LsSf https://astral.sh/uv/install.sh | sh
  2. 创建虚拟环境：
    uv venv venv --python 3.11
  3. 激活环境：
    source venv/bin/activate
  4. 安装 Node.js 22（推荐用 nvm）：
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
  5. 然后：
    nvm install 22 && nvm use 22
  6. 克隆仓库：
    git clone https://github.com/NousResearch/hermes-agent.git
  7. 进入目录：
    cd hermes-agent
  8. 安装 Python 依赖：
    uv pip install -e ".[all]"
  9. 安装 Node.js 依赖：
    npm install

配置 API Key（关键步骤）

Hermes 需要大模型 API Key 才能工作。以获取 OpenRouter API Key 为例（推荐，聚合200+模型）：
  1. 访问 https://openrouter.ai/ 注册账号
  2. 在 Dashboard 页面找到 API Keys，点击 "Create new key"
  3. 复制生成的 API Key（以 sk-or- 开头）
  4. 在终端运行：
    hermes config set OPENROUTER_API_KEY sk-or-你的密钥
密钥会自动保存到 `~/.hermes/.env` 文件。你也可以手动编辑这个文件：

编辑配置文件 nano ~/.hermes/.env  # 添加以下内容（以 OpenRouter 为例） 

OPENROUTER_API_KEY=sk-or-你的密钥

启动与验证

配置完成后，就可以启动 Hermes 了：
  1. 启动终端界面：
    hermes --tui
  2. 或者启动 Web Dashboard：hermes dashboard
  3. Web Dashboard 默认在 http://localhost:3000 打开
  4. 在界面中测试对话，比如输入："你好，帮我列出当前目录的文件"

接入微信/飞书（可选）

如果你想让 Hermes 在微信里工作：
  1. 运行：
    hermes gateway setup
  2. 选择 WeChat（微信）
  3. 用手机微信扫描二维码登录（建议用小号测试）
  4. 登录成功后，Hermes 就会出现在你的微信联系人里
  5. 在微信里发消息，它会自动回复并执行任务

七、总结与建议

为什么选择 Hermes Agent？

  • 真正开源：MIT 协议，可自由修改、分发、商用
  • 自我进化：Skills 机制让它越用越聪明，节省重复劳动
  • 灵活接入：支持微信等常用软件，随时随地使用
  • 模型中立：不绑定特定厂商，按需切换降低成本
  • 社区活跃：GitHub 13万+ Star，问题响应快

给新手的建议

  • 从简单任务开始：先让它整理文件、总结文档，熟悉工作模式
  • 善用 Skills：完成复杂任务后，检查生成的 SKILL.md，理解它的思考过程
  • 注意安全：先在小范围目录测试，再授予重要文件权限
  • 备份配置：定期备份~/.hermes 目录，防止丢失 Skills 和记忆
  • 加入社区：遇到问题去 GitHub Issues 或 Discord 社区求助
Hermes Agent 最大的吸引力在于它的**自我进化能力**——你教它的越多，它就越懂你、越高效。如果你想要一个不绑定特定模型、能接入微信飞书、还能自己学会新技能的开源AI助手，Hermes Agent 绝对值得一试。
