DeepSeek Harness 负责人，公开推荐了一个第三方社区的 skill


DSH 团队负责人崔添翼，在 X 上亲自下场，推荐了一个第三方社区做的 skill：dsh-plugin-upgrade-skill。

这个 skill 专门帮 DSH 插件作者升级自己的插件、适配 DSH 新版本。

DSH 迭代快，插件生态有个绕不开的问题：平台一发新版本，插件作者就得跟着改代码。改慢了，插件就不好使了。做插件的人都有体会：来来回回跟着改，特别麻烦。

崔添翼说得挺清醒：长远看，插件生态不能靠作者每次都手动适配。他给了两条路：

1

DSH 自己减少破坏性变更

2

加一层兼容，让面向旧 API 写的插件，在新版本里照样能跑

说白了，就像老的桌面系统、老的手机系统上写的程序，拿到新系统里还能打开。

dsh-plugin-upgrade-skill 是 oh-my-dsh 组织出的。oh-my-dsh 和 omdsh-dev 是最早的一批 DSH 插件作者独立社区，上面有不少高质量插件。

注意：这俩社区和 DeepSeek AI 之间没有隶属关系，纯独立开发者组织。推文原文也特意声明了，别误会成官方出品。

一个平台负责人，公开推荐第三方社区的工具，这本身就是信号：DSH 想做成生态，不是自己一家吃独食。

插件市场要活，关键是让写插件的人别那么累。毕竟，谁让作者省事，作者就去谁那。
