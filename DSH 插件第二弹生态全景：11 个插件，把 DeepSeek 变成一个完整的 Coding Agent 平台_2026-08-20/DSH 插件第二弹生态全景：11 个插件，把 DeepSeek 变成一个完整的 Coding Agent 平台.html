DSH 插件第二弹生态全景：11 个插件，把 DeepSeek 变成一个完整的 Coding Agent 平台

如果你最近关注国产 Coding Agent，一定绕不开 DSH（DeepSeek Harness） 这个名字。

它不是一个 App，而是一个类似 Claude Code 的官方 CLI + 运行时框架，核心特点是「一切皆插件」——基于 Cordis 插件系统 + profile 机制，官方能力和第三方能力走的是同一套 API，任何人都能给它写皮肤、写工具、写外壳。

过去几个月里，围绕 DSH 已经长出了一整个插件生态。今天这篇文章，我把其中 11 个最值得一试的插件 系统梳理一遍——从外壳、工作台到能力扩展、数据迁移，再到分发与娱乐层，你会看到一个 DeepSeek 系 Coding Agent「完整发行版」正在成形的样子。

一、外壳三件套：Web、终端、桌面全都要

外壳（Shell） 是你和 Agent 交互的第一层皮。DSH 一次性提供了三种。

1. dsh-web-ui：浏览器里的全家桶

dsh-web-ui 是官方为 Web 端准备的插件与皮肤集合，一句 dsh plugin --profile web add 就能挂载。里面塞满了硬货：梁神模式（V4 Pro 实测均分 98.5，用来榨干模型上限）、任务看板、Git 关系图、SSH 终端、移动端远程、图像理解、桌面宠物，外加 12 款皮肤任你切换。

最巧的是「Host 级 cron 定时任务」——即使你把浏览器关了，定时任务照样在后台执行，非常适合把 Agent 当成一个真正的「常驻工人」用。

2. dsh-TUI：Claude Code 风格的终端体验

如果你是极客党，dsh-TUI 是为你准备的。它把 Claude Code 那套 TUI 美学搬到了 DSH：像素鲸鱼顶栏、TPS 仪表、上下文进度条、流式 Markdown 渲染、@ 引用文件、Enter/Tab/Ctrl+Enter 三态操作、斜杠命令完全对齐 Claude Code。

已被官方公众号收录，卸载零残留，是纯终端玩家的首选。

3. DSH Desktop：Tauri v2 打造的原生桌面外壳

DSH Desktop 用 Tauri v2 + Rust 负责窗口、托盘、子进程管理，业务界面通过 iframe 复用 Web UI——一份代码两端跑。

它最聪明的一点是生命周期管理：检测到 3080 端口已有实例就复用，没有就自己拉子进程，而且只回收自己启动的进程。首次启动会自动下载 Node runtime + DSH 运行时，托盘、window.open、Notification 全部桥接到原生系统。装完就像装了一个正经桌面 App。

二、工作台层：把 IDE 塞进侧边栏

4. DSH-better-sidebar：右侧栏 + 底部面板的 IDE 化改造

better-sidebar 走的是「IDE in Sidebar」路线：右侧栏 7 个 tabs + 6 种 viewer——文件树、CodeMirror 编辑器、内嵌浏览器、xterm.js 真实终端、Git diff 面板、后台任务页，全部现成可用。

关键是它服务化了：ctx.betterSidebar 服务对第三方开放，任何插件都能注册自己的 tab 和 viewer，能力对等。启动包只有 325KB，重依赖懒加载，性能压得很稳。

一句话总结：它把 VS Code 那套「文件 + 编辑器 + 终端 + Git」的心智模型，塞进了浏览器右边一条侧栏里。

三、能力扩展层：眼睛、手和长期记忆

Agent 光会写代码是不够的，它得能看、能操作、能记住。这一层是 DSH 生态里最有想象力的部分。

5. dsh-browser：让 Agent 接管你的真实 Chrome

dsh-browser 是一个 Chrome MV3 侧边栏扩展 + DSH 桥接插件，目标只有一个：让 Agent 直接操作你已登录的 Chrome 标签页——保留 cookie、保留登录态、保留会话。

它的实现相当讲究：

  • • 页面序列化为结构化文本 + 控件编号，截图不进模型，token 极省；
  • • 密码、卡号永远打码，安全设计前置；
  • • 基准测试比 Playwright 快 1.24 倍。

对比动辄要开无痕、要重登录的 Playwright 方案，它更像一个「AI 版的 Chrome 助理」。

6. ModLens：给纯文本模型装上「眼睛」

DeepSeek、GLM 这类顶级编码模型有个尴尬——不支持看图。ModLens 就是为此而生的视觉插件。

它做的事情听起来很像 Vision，但形态完全不同：不输出自由描述，而是输出结构化 JSON 证据（OCR + 版面 + 语义实体）。你在聊天里直接粘贴截图，Agent 拿到的就是「这是一张登录页、包含 3 个输入框、按钮文字是 xxx」这样的可编程结果。

它内置 6 家 Provider + 4 个本地 CLI（复用已登录状态），组成一条 10 个视觉源的 failover 链，跨 Claude Code / Codex / Pi / OpenCode 通用——买一送多。

7. Graph Memory：让 Agent 拥有可追溯的长期记忆

graph-memory 解决的是所有 Agent 都躲不掉的痛点：跨会话的记忆。

它的做法很硬核：把对话抽取为 TASK / SKILL / EVENT 三类节点，用 USED_SKILL / SOLVED_BY 等类型化边关联，形成一张知识图谱。召回时走双路径——向量 + FTS5 精确召回负责细节，社区摘要负责泛化——再用 Personalized PageRank 做排序。

作者在测试场景中实测上下文 token 下降 75%。SQLite 默认存储，Pro 版还能接 Neo4j。

四、数据迁移层：从别的 Agent 无痛搬家

8. dsh-chat-import：16+ 外部工具的会话全导入

换工具最怕的是「历史丢了」。dsh-chat-import 支持从 Claude Code、Codex、Cursor、Gemini CLI、Kimi、ChatGPT 等 16+ 外部 Agent 把对话历史全保真导入 DSH——工具调用、推理过程、时间戳一个不落，按 cwd 自动分组工作区。

更进一步：它还支持反向导出、双向同步，以及 SHA-256 校验的可移植 bundle，甚至连 agent、MCP、settings 这些周边配置都能一起搬。你从 Claude Code 迁过来，几乎无感。

五、分发层：让插件被人看见、被人找到

生态要活，光有插件不够，还得有市场和发现机制。

9. dsh-market：可视化的官方内置的插件市场

dsh-market 是 DSH 内置的可视化插件市场，目前覆盖 1550+ 社区插件。

功能对标 App Store：分类搜索、截图预览、主题市场、一键安装、WebDAV/Gist 备份恢复、批量更新、诊断面板、AI 修复提示词、脱敏日志导出。所有安装都基于 cordis.patch.yml 热禁用启用，且只安装 awesome-dsh-plugin白名单内的插件——安全和体验都在线。

10. dsh-find-plugins：用自然语言找插件

有了 1550+ 插件，问题变成「怎么找到自己需要的」。dsh-find-plugins 是一个 Skill：你直接问「有没有插件能帮我 xxx？」，它会从 GitHub 的 dsh-plugin topic 里搜候选，识别是 bundle / Cordis / Skill 哪种类型。

更贴心的是——安装前会自动做安全审查：检查 lifecycle scripts、外网请求、子进程调用、凭据读取行为，把风险点显式告诉你。灵感来自 vercel-labs/skills。

六、娱乐层：也要能玩

11. Awesome DSH Pet：可扩展的桌面宠物

最后一个，也是最放松的一个。Awesome DSH Pet 是 Web GUI 右下角的桌面宠物系统，自带鲸鱼总裁和噜噜水豚两只官方吉祥物。

它把「造宠物」做成了纯资源活：一份 8×9 的 Codex spritesheet atlas + manifest.json，三步就能上线新宠物。仓库里还带了 verify-assets.mjs 门禁脚本，强制校验 15 个必需状态（idle / working / celebrate / error 等）——画师和策划自己就能提 PR，完全不写代码。

你的 Agent 在跑长任务时，右下角有只鲸鱼陪你打转，工程体验瞬间就不一样了。

生态定位小结

把这 11 个插件放在一张图里看，DSH 已经形成了一套分层完整的 Agent 工作平台：

  • • 外壳层：Desktop（桌面）、TUI（终端）、Web（浏览器）
  • • 工作台层：better-sidebar（IDE 化侧栏）、web-ui（皮肤 + 任务看板 + 移动远程）
  • • 能力扩展层：browser（浏览器操控）、ModLens（视觉）、graph-memory（长期记忆）
  • • 数据迁移层：chat-import（跨 Agent 会话迁移）
  • • 分发层：market（可视化市场）、find-plugins（AI 发现）
  • • 娱乐层：pet（桌宠）

对标 Claude Code 生态，DSH 通过 Cordis + profile 机制 走出了一条不太一样的路：开放插件市场 + 服务化架构，第三方与官方能力完全对等——你今天写一个皮肤，明天就能上到市场里给一千多个用户用。

如果说 Claude Code 定义了 Coding Agent 的 UX 范式，那 DSH 这套生态更像是国产 DeepSeek 系 Coding Agent 的「完整发行版」雏形：装完不是一个孤零零的 CLI，而是一整套「桌面 + 终端 + Web + 视觉 + 记忆 + 浏览器 + 插件市场」的开发工作台。

对开发者来说，这是一个非常值得关注的窗口期——生态刚起步、活跃度高、造插件门槛低、能被看到。想上车的话，从 dsh-market 逛一圈开始就够了。
