01 / 项目是什么：把欧美版，改成中国证券市场版

① 原版盘点：anthropics/financial-services（Apache 2.0）

面向欧美市场的 Claude 参考实现合集，覆盖投行 IB / 股票研究 ER / 私募股权 PE / 财富管理 WM / 基金行政 / 运营六大垂直域，含 55 个 skill、12 个欧美商业数据连接器、10 个命名 agent。盘完一遍，最关键的判断有两条：

· 约 70% 的文本内容是「市场无关」的方法论——Excel 工程规范、PE 工作流、fund-admin 会计流程、报告框架，可直接复用。
· 但数据接入层 100% 需要替换——SEC EDGAR / 10Y 美债 / GAAP / 美国税制 / wash sale；流程文件层（CIM / teaser / TLH / financial-plan）也得按中国实务重写。

AI 在金融里最稳的落点，永远是
「可审计的结构化」，而不是「自由生成」。
越规则、越可审计、越高频的环节，越先 AI 化。

② 关键决策：迁移复用，而非重写

改造的方法论蓝图，直接来自我们 6–8 月连发的《金融AI_Skill指南》系列 12 期——上面那句总铁律就是底层逻辑。早期 Daostock 季报引擎（Dao-financial-services 前身）已按系列第 2 期路线做过 4 轮季报 skill 迭代（791 行引擎、66 个用例、24 个数据源、A 股规则资产），这些资产被直接收编进新项目，避免了重复踩坑。

03 / 中国化改造，到底改了什么

① 四道关卡：原版依赖 → 中国版替换

数据源：CapIQ / FactSet / Daloopa / LSEG → 万得 / 同花顺 iFinD / 东财 Choice（商用）；akshare / tushare / 巨潮（免 key demo）

会计准则：US GAAP / non-GAAP → CAS（商誉不摊销只减值、双口径披露）

术语结构：美式概念（wash sale / CIM / precedent）→ 对赌 / 明股实债 / 换股吸并 / 勾稽 / 底稿 / 申万中信分类

监管合规：原版无内嵌 → 合规词表 + 评级白名单 + 留痕审计 + AI 角色明示 + 签字发布

② 原版没有的「中国特有机制」

配置化降级链 + 显式缺数：Tushare(L1)→AKShare(L2)→巨潮 PDF(L3) 自动降级；任一源失败不阻塞，缺数一律标注 [数据缺失]，绝不编造，来源 + 可信级（L1/L2/L3）随输出携带。

中文金融语境适配：亿/万/万亿/元组合解析器、括号负、千分位；语调词典「保守优先」（「负增长」→下调、「基本符合预期」＝陷阱提示）；A 股累计口径 → 单季派生（H1−Q1，防把累计误当单季比）。

机制替换（最关键动机）：A 股无资本利得税，rebalancing 把原版 wash sale / 税务亏损收割整体替换为「摩擦成本感知」——佣金 + 印花税 + 冲击成本，约束求解 + 审批留痕。

留痕审计 + 永不自动决策：告警/审批落 JSONL（系统时间戳、append-only），监管能回溯「你何时发现偏离」；评级段永远 [待人工]，AI 不下单、不评级、不生成目标价。

③ 贯穿红线：AI 初稿声明 + 防投毒

所有 AI 生成内容随输出携带「初稿声明」；PDF 自由文本用 <untrusted> 包裹防提示注入——这正是对 Anthropic 原版「不信任文件内容」设计的本土化继承。


04 / 真实跑测：不是 demo，是真财报、真行情

📄 案例一 · earnings：康希诺 688185（2026-08-28 科创板半年报）

· --fetch-pdf 自动从巨潮下载当日披露的《2026 年半年度报告》（1.4MB）
· akshare(L2) 与 PDF 交叉验证零偏差：营收 288.97 亿（+38.9%⚠）= PDF 28,897,478,718.36 元
· PDF 补缺扣非 −5,004.86 万 / 利润总额 +603.79 万 / 经营现金流 −1.07 亿
· 修复前输出是误导性的「增幅 +94.7%」，修复后正确为「亏损收窄 94.7%⚠」「扭亏为盈（增加 8012.78 万）」
· 合规扫描零命中；[待人工] 评级占位正确

同批还跑了牧原 002714（深市，由盈转亏「减少 166.08 亿」、猪周期毛利率 −1.58% 被指标正确捕捉）、茅台 600519（降级链无 token 时优雅工作）。初稿 <1 分钟（含 PDF 下载 2–3 分钟），对比人工 60 分钟——已超出「60→10 分钟」验收目标。

📊 案例二 · 组合 E2E：1,000 万组合，5 股 × 67 交易日真实行情

· 标的：茅台 20% / 药明 20% / 牧原 10% / 宁德 30% / 中芯 20%（2026-05-26~08-29，5 股 + 沪深300 + 4 申万指数全部真实行情，东财断连→新浪接住，来源标注）
· 指标面板：年化 +26.75%｜波动 26.95%｜Sharpe 0.93｜回撤 −7.81%｜β 0.89｜主动 +64.36%（年化）｜IR 3.76
· 行业贡献（恒等式闭合）：医药 +931.1 / 农林牧渔 +103.0 / 食品饮料 +102.2 / 电力设备 −194.0 / 电子 −217.3 = +725bps = 组合期间 +7.25% ✅
· Brinson：选股 +1551.7bps 主导（药明 +51.2% 双源交叉验证），恒等式 ✅
· 漂移：药明 20%→27.3%（超阈值）+ 医药行业 >25% 上限 → 2 条告警落 JSONL
· 再平衡：5 笔交易买卖配平，摩擦成本 2,360 元（佣金 457 + 印花 381 + 冲击 1,523，解析解验证），换手 18%，状态「待审批」落痕

防伪：药明期间收益经腾讯 / 新浪双源独立核对（+51.2% 一致），确认非数据伪影。这是一条从「盯盘 → 归因 → 再平衡」的可审计自动化流水线全链路跑通。


05 / 质量怎么保证：STDD 全流程 + TDD 真拦截

① STDD 双驱动 + 约 10 个 TDD 真拦截

开发同步跑自研 STDD（Spec+Test 双驱动）——10 个 change 全部走四阶段（proposal YAML-first / design / specs GIVEN-WHEN-THEN-SHALL / test-plan TC 映射），外层超循环双门人控。最硬的是 TDD 全程真实拦截了约 10 个缺陷，而非测试写完才发现：

恒真测试（最深认知修正）：Brinson BHB 三效应之和与主动收益是代数恒等，原「不闭合」测试对任意权重都成立——是恒真测试。重构为三层防线（权重和=1 前置守卫 / NaN 显式拦截 / 恒等式当哨兵）。

投影假通过：再平衡某用例「通过」是因为再分配顶破了自己刚设的上限——假通过。加不可行预检（n×cap<1 直接报错）+ 逐轮终检修掉。

前导零事故：pandas 把股票代码 000001 读成 int → 1，dtype={"code": str} 落地——正是 clean-data-xls 注记预言过的事故，防线提前声明。

年化波动 ddof 口径：解析解期望值按 ddof=0 写（√2），实现是样本口径 ddof=1（√(4/3)）——测试先行暴露，修正测试。

NaN 静默通过：abs(NaN−NaN)>tol 恒 False，任何比较校验都会被 NaN 绕过——必须 math.isfinite 显式拦截。

② 诚实记录

首包曾出现超循环「超 2 违规自行 close」，全面审计后补交互追认、建立 6 条防线；两个超循环合并复盘，沉淀 29 项遗留清单。经验库现有 8 条（detection-trigger + fix-template 格式），跨项目自动复用。

🎯 小以观察

观察一：最值钱的不是那 2,000 多行引擎代码
而是我们把金融 AI 落地里那些「看不见的坑」——累计口径误比、负值语义丢失、NaN 静默通过、恒真测试自欺、前导零事故——一个个用 TDD 钉死的工程纪律。这些东西不会写在 demo 里，却是真敢拿去生产的分水岭。

小以判断：把判断留给人、把机械活交给 AI、把每一步留痕——
这套「人在关键节点签字」的设计，既是对 Anthropic 原意的继承，
也是中国证券市场合规底线的硬要求。
