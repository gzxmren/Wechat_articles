我的 AI Agent 学会赚钱了...
这是苍何的第 549 篇原创！

大家好，我是苍何。

前两天有朋友问我：你的 Agent 现在能干嘛？

我说我的 Agent 会自己赚钱了🐶。

他说，你就吹牛吧。

我把电脑屏幕转过去给他看。

上面是我的开源产品 Wesight 推过来的实时进度，我的 Agent 正在 ClawHunt 上竞标，刚刚又中了一单😄。

他盯着看了几秒，没说话。

讲真，这种「我睡觉它打工」的感觉，还挺爽的。

那这套「躺赚」的流程到底怎么跑起来的？

下面我把整个过程完整拆给你看。

首先打开 ClawHunt 任务广场，你会发现有很多任务，每个都有悬赏金额。

比如这是个修 bug 的任务，想修复 MoviePy 版本不匹配问题。

我还看到公司知识库 AI 智能检索这个任务，足足有 100 刀的赏金啊，讲真，有辣么一点点替我的 Agent 心动。

这个模式就是，需求方挂任务、开发者部署 Agent 接活，平台用法币结算，验收后付费。

我的 Agent 可以去赚钱，我也能反过来把需求挂上去让别的 Agent 来竞标完成。

搞清楚定位之后，我就动手让自己的 Agent 上岗。

首页直接给了安装命令，我把命令丢给 Wesight。

●●●curl -fsSL https://clawhunt.store/install | bash -s -- --name my-agent

跑完之后，Wesight 会给我一个认领链接。

登录之后，我的 Agent 就有了一张「上岗证」。

接着，我让 Wesight 继续跑通「入职」流程。

让 Agent 自己去「入职」。

随后，我在 ClawHunt 的「My Agents」里就看到了它。

到这一步，Agent 就算正式上岗了。

最有意思的是，部署完之后，根本不用我一步步去点。

Agent 自己就溜进了任务市场，挑选适合自己的任务，参与竞标和执行。

点开某一条任务，还能看到更细的信息。当前状态、执行进度、交付情况，全都一目了然。

等 Agent 交付任务、发起方验证通过，钱包余额立马就到账了。

这件事真正让我兴奋的是它验证了一个模型：Agent 的边际成本几乎为零。

你部署 1 个 Agent 和部署 10 个 Agent，除了 API 调用费，人力成本没有区别。传统外包是「一个人干一份活」，Agent 经济是「一套 Prompt 干 N 份活」。

这意味着什么？意味着未来可能出现一种新职业：Agent 训练师。不写代码，专门调教 Agent 的任务理解能力和交付质量，然后批量部署到各个平台上接单。

说白了，从「卖自己的时间」变成「卖 Agent 的时间」，这才是真正的杠杆。

钱包也很顺手，既能充值用来发布任务，也能在任务交付后直接提现。

相当于一个 Agent 版的「支付宝」。

我让它跑了一周，接了 1 单，到账 10 刀。说实话，这个数不算多，但关键是这一周我啥也没干。

换算一下，相当于我多了个 7 x 24 小时不休息、不摸鱼、不要五险一金的「实习生」。

当然也翻过车。有一单它提交的代码没过验收，被打回来了。我看了下原因，是任务描述太模糊，Agent 理解偏了。这说明现阶段 Agent 不是万能的，任务的描述质量直接决定交付质量。

除了能赚钱，ClawHunt 上还有一个我很在意的点。

那就是 Agent 的活动是可被观察的。

我能在实时动态里看到 Agent 的活动记录。

它正在看哪个任务、执行到哪一步、当前状态如何，整条链路都是透明、可追溯的。

过去用 Agent 像开盲盒，Prompt 丢进去，中间在干什么完全看不见。

而 ClawHunt 把每一步动作、每一次状态切换都记录下来。

Agent 终于不只是「能跑」，而是可以被管理、被追踪、被复盘。

要知道 Agent 最大的问题是干错了你都不知道。

之前我用 Agent 帮我处理数据，跑完告诉我已完成。结果我一看，它把表头当数据处理了，整个结果全是错的。

更可怕的是，如果我不检查，这份错误数据就直接交付出去了。

所以 Agent 的可观测性不是锦上添花，是刚需。就像你不会让一个新员工独立干活还不汇报一样，Agent 也需要「日报」。

ClawHunt 里还有个挺有意思的功能，叫 Agent Arena，不同 Agent 在真实任务里同台竞技。

过去判断 Agent 好不好用，基本靠主观体感。Arena 直接用 结果质量、完成效率、交付表现 说话，谁强谁弱一目了然。

我还顺手试了 ClawHunt 的「SuperClaw」，SuperClaw是 AI Agents 工作区。

它会自己规划、执行、验证，并留下可复核的证据。

除了让 Agent 赚钱，ClawHunt 社区也在做孵化。

如果你有现成的 Agent 产品，或者正在孵化中的项目，他们会提供项目背书、早期 token 支持、产品推广和社区质检，还会把优秀项目推荐给 VC 和潜在 B 端客户。

我进了他们官方群，发现他们最近打算搞 3 天线下黑客松。

让开发者现场组队做能承接真实业务需求的 Agent，优秀项目能进 ClawHunt 孵化器，拿官方背书、早期 token 额度、VC 对接和产品推广。

这种黑客松还是第一次见，相当于教你的 Agent 如何去赚钱。

而且 Clawhunt 黑客松产出的 Agent 可直接上架平台承接真实任务，获得持续收益。

相当于他们是想让 AI Builder 们，让这些真正在搞事情的人，被看见、被连接、被推到台前。

说实话，写到这我也有点感慨。

AI Agent 正在从「能干活」走向「能赚钱」，这件事比我预想的来得快多了。

风口面前，比工具更值钱的，是身边一起折腾的人。

如果你也想让 Agent 上岗赚钱、想招 Agent 替你干活、想做 AI 创业找方向、想提前看一波早期项目，可以加入「爪寻 AI 社区」一起唠唠。

我的判断是，2026 年下半年会是 Agent 商业化的分水岭。

上半场大家比的是谁的 Agent 更聪明，下半场比的是谁的 Agent 能稳定交付、持续赚钱。

ClawHunt 做的事情，我感觉本质上是给 Agent 搭了一个「人才市场」。需求方不用管 Agent 是谁家的、用什么模型，只看结果付费。

这个逻辑跟当年的 Upwork、猪八戒网一模一样，只不过干活的从人变成了 Agent。

区别在于，人有上限，Agent 没有。
