Claude Code + NotebookLM + Obsidian：一个越用越聪明的科研怪兽


大多数人在做研究时，仍然靠手动操作。

打开 10 个标签页。看视频。读文章。在某处记笔记。一小时后，你得到一堆不知道该怎么处理的信息。

本文是一份完整的指南，教你如何用 Claude Code、NotebookLM 和 Obsidian 搭建一个研究流程，能够调研任何话题——市场动态、新兴技术、加密货币生态、内容利基等等——并且每次使用它，它都会变得更聪明。

⏱ 搭建时间：不到 30 分钟

这套技术栈为什么有效

四个工具，各司其职。

  • Claude Code
     — 执行引擎。它运行命令、调用技能、管理文件、协调整个流水线。你用自然语言告诉它做什么，它就去做。
  • Skill Creator
     — 定制层。一个 Claude Code 插件，让你用自然语言构建可复用的技能。你描述需求，它生成代码并安装技能。无需编程。
  • NotebookLM
     — 分析引擎。Google 的 AI 研究工具，读取你的资料并生成深度分析、摘要、信息图、闪卡、播客脚本等。当 Claude Code 将处理工作卸载到 NotebookLM 时，它用的是 Google 的计算资源，而不是你的 Claude tokens。
  • Obsidian
     — 记忆层。一个基于 Markdown 的本地知识系统，存储工作流产生的所有内容。随着时间的推移，Claude Code 读取这些文件，学习你的思维方式、关心什么、以及你喜欢怎样的分析结果。

结合起来：一个根据指令执行、大规模分析、越用越好的研究系统。

第一步：安装 Skill Creator

打开 Claude Code。确保你在 Obsidian 仓库文件夹内——这对 Obsidian 拾取 Claude Code 生成的文件很重要。

运行以下命令：

/plugin

搜索 skill-creator，安装。退出 Claude Code，重启。你现在可以用自然语言描述来创建任何技能了。

第二步：创建 YouTube 搜索技能

这个技能让 Claude Code 能够搜索 YouTube 并提取结构化的视频数据——标题、频道、订阅数、播放量、上传日期、URL、以及互动转化率。

在 Claude Code 中运行：

/skill-creator I want to create a skill that searches 
YouTube and returns structured video results. 
It should use yt-dlp to search for videos by query, 
return the top 20 results by default, and include 
metadata for each video - title, channel name, subscriber 
count, view count, duration, upload date, and URL. 
It should filter to the last 6 months by default but support 
a --months flag to change that. 
It should also calculate a views-to-subscribers 
ratio as an engagement metric. 
The output should be nicely formatted with 
dividers between each result and human-readable numbers.

Claude Code 将生成技能、安装并确认。你现在有了 /yt-search 命令。

注意： yt-dlp 需要在你的机器上安装。

第三步：安装 NotebookLM-py

NotebookLM 没有公开 API。为了将 Claude Code 连接到 NotebookLM，我们使用一个开源项目 notebooklm-py。

仓库地址：github.com/teng-lin/notebooklm-py

在终端中运行以下命令（不要在 Claude Code 中运行）：

pip install notebooklm-py

然后进行身份认证：

notebooklm login

浏览器窗口将打开。登录你的 Google 账号。完成，连接已建立。

第四步：创建 NotebookLM 技能

现在你需要教会 Claude Code 如何使用 notebooklm-py。在 Claude Code 中运行：

/skill-creator create a skill so we can best use the 
notebooklm-py tool. Reference the GitHub repo at 
github.com/teng-lin/notebooklm-py and build 
a skill that can: create new notebooks, add sources 
(YouTube URLs, text, files), run analysis on those sources, 
and generate deliverables including audio overview, 
mindmap, flashcards, and infographic.

这为 Claude Code 提供了完整的 NotebookLM 技能，涵盖 NotebookLM 支持的所有操作——每个 notebook 最多 50 个来源，所有交付类型。

第五步：将所有内容组合成一个流水线技能

这是工作流真正变得强大的地方。

不再是手动运行 YouTube 搜索，然后发送结果到 NotebookLM，再请求分析——你构建一个技能，按单个命令依次完成所有步骤。

在 Claude Code 中运行：

/skill-creator I want to create a YouTube research pipeline 
skill that combines the yt-search skill and the 
NotebookLM skill. When I use this pipeline skill I want 
it to: take what I told it to research, go to YouTube and 
find 10 relevant videos using the yt-search skill, use 
the NotebookLM skill to create a new notebook, 
add those video sources to the notebook, then do 
analysis on the topic based on what I said when 
I invoked the skill. Furthermore ask me if I want 
a deliverable - NotebookLM can create flashcards, 
infographics, mindmaps, audio overviews. 
If I don't specify a deliverable assume none. 
After analysis bring everything back to me in a
markdown file saved to the vault, and also show 
it in chat. Include all YouTube search metadata 
in the output - sources used, view counts, 
channel names, engagement ratios.

运行工作流

/yt-pipeline I want to research AI agent frameworks in 2026. 
Which frameworks are developers actually adopting -
- LangGraph, CrewAI, AutoGen, Agno, or something else? 
I want to understand what's driving views on this topic, 
where there's disagreement in the community, 
what the outliers are, and what angles haven't been 
covered well yet. Find 10 relevant sources, 
push them to a new NotebookLM notebook, 
run a full analysis, and generate an infographic 
showing the landscape.

有了流水线技能，这就是一次真实的研究会话。

Claude Code 启动流水线。它调用 YouTube 搜索技能，找到 10 个涵盖框架教程、对比和开发者评价的视频——将 URL 传递给 NotebookLM，创建 notebook，运行分析，并请求生成信息图。

总处理时间：约 6 分钟。 其中大部分时间是 NotebookLM 在 Google 服务器上处理——而不是你的 Claude tokens。

最终结果包括：

  • 一份完整的分析，涵盖哪些框架在上升 vs. 趋于平稳、开发者实际在抱怨什么、互动异常值、以及尚未被覆盖的内容空白
  • 一张映射 AI Agent 框架全景的信息图
  • 一个 Markdown 文件，直接保存到你的 Obsidian 仓库，结构完整并带有链接——方便在未来的研究中引用

为什么 Obsidian 让它成为完全不同的工具

以上所有内容都能作为一次性研究任务工作。

但 Obsidian 让它的价值不断累积。

工作流产生的每个 Markdown 文件都会落地到你的 Obsidian 仓库。随着时间的推移，你的仓库变成一个结构化的知识库，包含你研究过的所有内容——话题、资料、分析、模式、结论。

Claude Code 能读取所有这些文件。它看到它们是如何链接的。它理解你经常回到哪些话题、你发现哪些分析有用、你喜欢什么格式。

仓库中的 claude.md 文件是这一切显式化的地方。它是一个配置文件，告诉 Claude Code 如何与你协作——你的惯例、你的输出偏好、你希望事情如何组织。

你可以这样说来更新它：

Can we update claude.md so it better reflects 
my work style, analysis approach, and output 
preferences based on our latest conversations?

Claude Code 读取最近的会话，识别你的模式，并更新文件。

每周做一次。 一个月后，工作流已经足够了解你，输出开始符合你真正想要的内容，不需要大量提示。

一年后——如果你持续这样做——你将拥有一个已经吸收了数百个会话的研究系统，理解你的思维方式，像一个训练有素的助手而不是一个空白工具。

没人提到的模块化关键

YouTube 不是关键。流水线结构才是关键。

你可以用 Claude Code 能访问的任何数据源替换 YouTube：

  • PDF
     — 学术论文、行业报告、白皮书
  • 公开网页
     — 新闻文章、文档、博客文章
  • 本地文件
     — 你自己的笔记、导出的数据、转录稿
  • Google Drive
     — 你已有的文档和电子表格

工作流模板保持不变。替换数据源，保留结构。

  • 用白皮书和公开文档研究加密生态
  • 用 YouTube 上的会议演讲分析新兴技术
  • 通过分析表现最好的内容来绘制内容生态地图
  • 用公开报告研究市场动态

最终成果

一个研究系统，能够：

  • 按单个命令执行完整的研究流水线
  • 将重型分析卸载到 Google 的基础设施（NotebookLM）
  • 自动生成结构化交付物——信息图、思维导图、音频、闪卡
  • 将每次结果保存到本地知识库
  • 随时间学习你的偏好，不断改进输出质量

这 30 分钟的搭建，从你第一次使用就值回票价。
